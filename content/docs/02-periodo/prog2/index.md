A disciplina de Programação 2 aprofunda os conceitos de programação, introduzindo estruturas de dados mais complexas, orientação a objetos e boas práticas de desenvolvimento.

## Objetivos

- aprimorar habilidades de programação
- compreender programação orientada a objetos
- trabalhar com estruturas de dados avançadas
- aplicar boas práticas de desenvolvimento
- desenvolver projetos de maior complexidade

## Conteúdo previsto

- orientação a objetos
- classes e objetos
- herança e polimorfismo
- estruturas de dados avançadas
- padrões de design
