A disciplina de Programação 1 introduz os conceitos fundamentais da lógica de programação, do raciocínio algorítmico e da escrita de programas simples.

## Objetivos

- compreender a lógica de programação
- aprender a estruturar algoritmos de forma clara
- desenvolver habilidades básicas de resolução de problemas
- iniciar a prática com linguagem de programação

## Conteúdo previsto

- fundamentos de programação
- variáveis e tipos de dados
- estruturas de controle
- funções e modularização
- listas e estruturas básicas
