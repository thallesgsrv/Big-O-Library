## O que você vai aprender

Este estágio responde três perguntas: **o que é** um computador e um sistema computacional, **de onde ele veio** e **que tipos existem**. Não tem conta difícil. O que cobram é vocabulário preciso e a capacidade de ligar cada invenção ao problema que ela resolveu.

## Mapa do estágio

1. **Primeiros conceitos:** computação, informática, dado x informação, peopleware, hardware e software.
2. **Primórdios:** do ábaco aos cartões de Hollerith (até 1930).
3. **1930 a 1960:** relés, válvulas, ENIAC, transistor.
4. **1960 até hoje:** circuito integrado, microprocessador, PC, internet.
5. **Classificação:** gerações, analógico x digital, âmbito e porte.

## Cola rápida

| Ideia | Em uma linha |
| --- | --- |
| Dado | observação solta sobre o mundo; máquinas lidam bem com isso |
| Informação | dado com relevância e propósito; precisa de gente |
| Hardware / Software / Peopleware | a parte física / a parte lógica / as pessoas |
| 1ª geração | válvulas |
| 2ª geração | transistores |
| 3ª geração | circuitos integrados |
| 4ª geração | microprocessadores (VLSI) |
| Analógico x digital | o analógico **mede**, o digital **conta** |

## Como estudar

1. Leia as páginas na ordem. A história só fica fácil quando você enxerga a cadeia: *cada máquina tenta consertar o defeito da anterior*.
2. Faça os quizzes de cada página antes de abrir os gabaritos.
3. No fim, tente montar a linha do tempo de cabeça: ábaco, Pascal, Jacquard, Babbage, Hollerith, relés, válvulas, transistor, circuito integrado, microprocessador.
