# Código de Conduta

A Big-O-Library é feita por estudantes, para estudantes. Para manter o espaço bom para todo mundo:

- Trate as pessoas com respeito, inclusive em discordâncias.
- Dê e receba feedback de forma construtiva.
- Não publique conteúdo ofensivo, discriminatório ou que viole direitos autorais.
- Não exponha dados pessoais de outras pessoas.

Comportamentos fora disso podem levar à remoção de comentários, Pull Requests ou issues. Para denunciar algo, abra uma [issue](https://github.com/thallesgsrv/Big-O-Library/issues) ou entre em contato com a pessoa que mantém o repositório.
