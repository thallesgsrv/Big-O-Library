Conversão entre Bases

Existem quatro técnicas básicas para inteiros: divisão, polinômio, agrupamento de 3 bits e agrupamento de 4 bits. Elas servem para qualquer par de bases. Escolha a certa para cada caso.

De → ParaTécnica
Decimal → outra baseDivisões sucessivas
Outra base → decimalPolinômio
Binário ↔ octalAgrupar de 3 em 3 bits
Binário ↔ hexadecimalAgrupar de 4 em 4 bits
Octal ↔ hexadecimalPassar pelo binário

1. Decimal para outra base: divisões sucessivas

Divida o número pela base de destino, depois o quociente, e assim por diante, até o quociente ser menor que a base. O resultado é o último quociente (MSB) seguido dos restos, do último para o primeiro (o primeiro resto é o LSB).

Exemplo: 53810538_{10}53810​ para binário.

DivisãoQuocienteResto
538 ÷ 22690
269 ÷ 21341
134 ÷ 2670
67 ÷ 2331
33 ÷ 2161
16 ÷ 280
8 ÷ 240
4 ÷ 220
2 ÷ 210
1

Lendo de baixo para cima: 53810=10000110102538_{10} = 1000011010_253810​=10000110102​.

Para outras bases é o mesmo processo, só muda o divisor:

  • Para octal: 538=8⋅67+2538 = 8\cdot67+2538=8⋅67+2; 67=8⋅8+367 = 8\cdot8+367=8⋅8+3; 8=8⋅1+08 = 8\cdot1+08=8⋅1+0. Resultado: 53810=10328538_{10}=1032_853810​=10328​.
  • Para hexadecimal: 538=16⋅33+10538 = 16\cdot33+10538=16⋅33+10; 33=16⋅2+133 = 16\cdot2+133=16⋅2+1. Resto 10 vira A. Resultado: 53810=21A16538_{10}=21A_{16}53810​=21A16​.

Importante

Os três resultados são o mesmo número escrito de três jeitos: 10000110102=10328=21A16=538101000011010_2 = 1032_8 = 21A_{16} = 538_{10}10000110102​=10328​=21A16​=53810​.

2. Outra base para decimal: polinômio

Qualquer número em qualquer base é um polinômio de potências da base:

N=an⋅bn+an−1⋅bn−1+⋯+a1⋅b1+a0⋅b0 N = a_n \cdot b^n + a_{n-1}\cdot b^{n-1} + \dots + a_1 \cdot b^1 + a_0\cdot b^0 N=an​⋅bn+an−1​⋅bn−1+⋯+a1​⋅b1+a0​⋅b0

onde aia_iai​ são os algarismos e bbb é a base. O dígito mais à direita tem expoente 0.

Binário: 11111012=64+32+16+8+4+0+1=125101111101_2 = 64+32+16+8+4+0+1 = 125_{10}11111012​=64+32+16+8+4+0+1=12510​.

Octal: 10328=1⋅512+0+3⋅8+2=538101032_8 = 1\cdot512 + 0 + 3\cdot8 + 2 = 538_{10}10328​=1⋅512+0+3⋅8+2=53810​.

Hexadecimal: FACE16=15⋅4096+10⋅256+12⋅16+14=6420610FACE_{16} = 15\cdot4096 + 10\cdot256 + 12\cdot16 + 14 = 64206_{10}FACE16​=15⋅4096+10⋅256+12⋅16+14=6420610​.

3. Binário ↔ hexadecimal: grupos de 4 bits

Como 16=2416 = 2^416=24, cada dígito hexa vira exatamente 4 bits.

  • Binário → hexa: separe de 4 em 4 da direita para a esquerda (complete com zeros à esquerda se faltar). 1011 1100 1010 01112=BCA7161011\ 1100\ 1010\ 0111_2 = BCA7_{16}1011 1100 1010 01112​=BCA716​.
  • Hexa → binário: troque cada dígito pelos seus 4 bits. 23B16=0010 0011 1011223B_{16} = 0010\ 0011\ 1011_223B16​=0010 0011 10112​.

4. Binário ↔ octal: grupos de 3 bits

Como 8=238 = 2^38=23, cada dígito octal vira exatamente 3 bits.

  • Binário → octal: separe de 3 em 3 da direita para a esquerda. 001 011 110 010 100 1112=1362478001\ 011\ 110\ 010\ 100\ 111_2 = 136247_8001 011 110 010 100 1112​=1362478​.
  • Octal → binário: 7238=111 010 0112723_8 = 111\ 010\ 011_27238​=111 010 0112​.

5. Octal ↔ hexadecimal: passe pelo binário

Não há relação de potência entre 8 e 16, então a conversão é em duas etapas: octal para binário (3 bits) e binário para hexa (4 bits), ou o contrário.

Exemplo: (175)8→(?)16(175)_8 \to (?)_{16}(175)8​→(?)16​.

  1. Octal para binário: 1,7,5→001 111 1011,7,5 \to 001\ 111\ 1011,7,5→001 111 101.
  2. Reagrupe em 4: 0111 11010111\ 11010111 1101.
  3. Para hexa: 7D167D_{16}7D16​.

Exemplo inverso: 21A16→(?)821A_{16} \to (?)_821A16​→(?)8​: 0010 0001 1010→001 000 011 010→103280010\ 0001\ 1010 \to 001\ 000\ 011\ 010 \to 1032_80010 0001 1010→001 000 011 010→10328​.

6. Números fracionários

A parte fracionária continua posicional, com expoentes negativos:

110,1012=1⋅22+1⋅21+0⋅20+1⋅2−1+0⋅2−2+1⋅2−3=4+2+0+0,5+0+0,125=6,625 110{,}101_2 = 1\cdot2^2 + 1\cdot2^1 + 0\cdot2^0 + 1\cdot2^{-1} + 0\cdot2^{-2} + 1\cdot2^{-3} = 4+2+0+0{,}5+0+0{,}125 = 6{,}625 110,1012​=1⋅22+1⋅21+0⋅20+1⋅2−1+0⋅2−2+1⋅2−3=4+2+0+0,5+0+0,125=6,625

Decimal fracionário para outra base: converta a parte inteira por divisões e a parte fracionária por multiplicações sucessivas pela base, anotando a parte inteira de cada resultado, até a fração zerar.

Exemplo: 8,375108{,}375_{10}8,37510​ para binário.

  • Parte inteira: 810=100028_{10} = 1000_2810​=10002​.
  • Parte fracionária: 0,375×2=0,750{,}375\times2=0{,}750,375×2=0,75 (bit 0); 0,75×2=1,50{,}75\times2=1{,}50,75×2=1,5 (bit 1); 0,5×2=1,00{,}5\times2=1{,}00,5×2=1,0 (bit 1). Fração zerou: 0,01120{,}011_20,0112​.
  • Resposta: 8,37510=1000,01128{,}375_{10}=1000{,}011_28,37510​=1000,0112​.

Nem toda fração fecha

Tente 5,8105{,}8_{10}5,810​: a parte fracionária 0,80{,}80,8 gera 0,8→0,6→0,2→0,4→0,8…0{,}8\to0{,}6\to0{,}2\to0{,}4\to0{,}8\dots0,8→0,6→0,2→0,4→0,8…, ou seja, repete 1100 para sempre. Então 5,810=101,110011001100…25{,}8_{10}=101{,}110011001100\dots_25,810​=101,110011001100…2​, uma dízima. É por isso que o computador não representa exatamente certos decimais (como 0,1 ou 5,8), e é a origem de erros de arredondamento que você verá em ponto flutuante.

Quiz

Qual a técnica mais rápida para converter 1011 011021011\ 0110_21011 01102​ para hexadecimal?

1011=B1011 = B1011=B e 0110=60110 = 60110=6, então B616B6_{16}B616​. 16 é 242^424, por isso grupos de 4 bits.

101021010_210102​ em decimal é:

8+0+2+0=108+0+2+0=108+0+2+0=10.

Por que 0,1100{,}1_{10}0,110​ não tem representação exata em binário?

0,1→0,2→0,4→0,8→1,6→1,2…0{,}1\to0{,}2\to0{,}4\to0{,}8\to1{,}6\to1{,}2\dots0,1→0,2→0,4→0,8→1,6→1,2… e o ciclo repete. É uma dízima em base 2, assim como 1/31/31/3 é em base 10.

Exercícios

  1. Converta 13010130_{10}13010​ para binário, octal e hexadecimal.
  2. Converta 11001011211001011_2110010112​ para decimal.
  3. Converta 111101001100010021111010011000100_211110100110001002​ para hexadecimal e octal.
  4. Converta 93,251093{,}25_{10}93,2510​ para binário.
  5. Desafio: uma caixa alienígena tem o número 25 gravado e contém 17 objetos. Quantos dedos o alienígena tem nas duas mãos (assumindo que ele conta em uma base igual ao total de dedos)?
Gabarito
  1. 130=100000102=2028=8216130 = 10000010_2 = 202_8 = 82_{16}130=100000102​=2028​=8216​.
  2. 128+64+0+0+8+0+2+1=203128+64+0+0+8+0+2+1 = 203128+64+0+0+8+0+2+1=203.
  3. Hexa: 1111 0100 1100 0100=F4C4161111\ 0100\ 1100\ 0100 = F4C4_{16}1111 0100 1100 0100=F4C416​. Octal: 001 111 010 011 000 100=1723048001\ 111\ 010\ 011\ 000\ 100 = 172304_8001 111 010 011 000 100=1723048​.
  4. Inteira: 93=1011101293=1011101_293=10111012​. Fração: 0,25×2=0,50{,}25\times2=0{,}50,25×2=0,5 (0), 0,5×2=1,00{,}5\times2=1{,}00,5×2=1,0 (1): 0,0120{,}01_20,012​. Resposta: 1011101,0121011101{,}01_21011101,012​.
  5. 25b=2b+5=1725_b = 2b+5 = 1725b​=2b+5=17, logo b=6b=6b=6. Ele tem 6 dedos (3 em cada mão).
