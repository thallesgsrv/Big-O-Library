Sobre

Ao dizer “o ponto (3,2)(3, 2)(3,2)”, você já usou coordenadas sem perceber: “3 passos para a direita e 2 para cima”. Os “passos” são medidos com as réguas (1,0)(1, 0)(1,0) e (0,1)(0, 1)(0,1), a base canônica.

A ideia desta página: nada obriga a usar essas réguas. Dá para medir o mesmo ponto com outras réguas (outra base), e as coordenadas mudam, mas o ponto continua o mesmo. Mudança de base é a ferramenta que traduz um endereço no outro.

Coordenadas numa base

Uma base ordenada é uma base em que a ordem dos vetores importa. Escrevemos B=(b1,…,bn)B = (b_1, \ldots, b_n)B=(b1​,…,bn​).

Como vimos, todo vetor vvv se escreve de um único jeito como combinação dos vetores da base:

v=a1b1+a2b2+⋯+anbn. v = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n. v=a1​b1​+a2​b2​+⋯+an​bn​.

Os números a1,…,ana_1, \ldots, a_na1​,…,an​ são as coordenadas de vvv na base BBB, e formam o vetor coordenado, escrito como coluna:

[v]B=[a1a2⋮an]. [v]_B = \begin{bmatrix} a_1 \\ a_2 \\ \vdots \\ a_n \end{bmatrix}. [v]B​=​a1​a2​⋮an​​​.

Como calcular: é só o problema de combinação linear. Monte o sistema v=a1b1+⋯+anbnv = a_1b_1 + \cdots + a_nb_nv=a1​b1​+⋯+an​bn​ e resolva.

Exemplo 1. Em R2\mathbb{R}^2R2, seja B=((1,1),(1,−1))B = ((1, 1), (1, -1))B=((1,1),(1,−1)) e v=(5,1)v = (5, 1)v=(5,1). Queremos a(1,1)+b(1,−1)=(5,1)a(1,1) + b(1,-1) = (5, 1)a(1,1)+b(1,−1)=(5,1):

{a+b=5a−b=1  ⟹  a=3,  b=2. \begin{cases} a + b = 5 \\ a - b = 1 \end{cases} \;\Longrightarrow\; a = 3,\; b = 2. {a+b=5a−b=1​⟹a=3,b=2.

Então [v]B=[32][v]_B = \begin{bmatrix} 3 \\ 2 \end{bmatrix}[v]B​=[32​]. Ou seja, (5,1)=3(1,1)+2(1,−1)(5, 1) = 3(1,1) + 2(1,-1)(5,1)=3(1,1)+2(1,−1).

Nota

Na base canônica, as coordenadas são os próprios números do vetor: [(5,1)]can=(5,1)[(5, 1)]_{\text{can}} = (5, 1)[(5,1)]can​=(5,1). Por isso “coordenadas” parecem não fazer nada nessa base: o endereço e o vetor são a mesma lista.

Exemplo 2. Em R2\mathbb{R}^2R2, B=((2,1),(1,−1))B = ((2, 1), (1, -1))B=((2,1),(1,−1)) e v=(5,1)v = (5, 1)v=(5,1):

{2a+b=5a−b=1  ⟹  3a=6,  a=2,  b=1. \begin{cases} 2a + b = 5 \\ a - b = 1 \end{cases} \;\Longrightarrow\; 3a = 6,\; a = 2,\; b = 1. {2a+b=5a−b=1​⟹3a=6,a=2,b=1.

Logo [v]B=(2,1)[v]_B = (2, 1)[v]B​=(2,1). Confira: 2(2,1)+1(1,−1)=(5,1)2(2,1) + 1(1,-1) = (5, 1)2(2,1)+1(1,−1)=(5,1). ✓ (O mesmo vvv do Exemplo 1 tem outro endereço em outra base.)

Exemplo 3: em R3\mathbb{R}^3R3. B=((1,2,3),(0,1,2),(0,0,1))B = ((1, 2, 3), (0, 1, 2), (0, 0, 1))B=((1,2,3),(0,1,2),(0,0,1)) e v=(1,3,5)v = (1, 3, 5)v=(1,3,5).

{a=12a+b=33a+2b+c=5  ⟹  a=1,  b=1,  c=5−3−2=0. \begin{cases} a = 1 \\ 2a + b = 3 \\ 3a + 2b + c = 5 \end{cases} \;\Longrightarrow\; a = 1,\; b = 1,\; c = 5 - 3 - 2 = 0. ⎩⎨⎧​a=12a+b=33a+2b+c=5​⟹a=1,b=1,c=5−3−2=0.

Então [v]B=(1,1,0)[v]_B = (1, 1, 0)[v]B​=(1,1,0).

Antes de calcular: BBB precisa ser base. Neste exemplo, a matriz com esses vetores é triangular com 1 na diagonal, determinante 1. Os três vetores são LI e, como dim⁡R3=3\dim \mathbb{R}^3 = 3dimR3=3, formam uma base.

O caminho de volta

Se você tem as coordenadas e quer o vetor, é só montar a combinação:

[v]B=[1−23]  ⟹  v=1(1,2,3)−2(0,1,2)+3(0,0,1)=(1,  2−2,  3−4+3)=(1,0,2). [v]_B = \begin{bmatrix} 1 \\ -2 \\ 3 \end{bmatrix} \;\Longrightarrow\; v = 1(1,2,3) - 2(0,1,2) + 3(0,0,1) = (1,\; 2 - 2,\; 3 - 4 + 3) = (1, 0, 2). [v]B​=​1−23​​⟹v=1(1,2,3)−2(0,1,2)+3(0,0,1)=(1,2−2,3−4+3)=(1,0,2).

Esse sentido não precisa de sistema: é só uma conta.

Polinômios e matrizes

Nada muda: as coordenadas são os coeficientes da combinação.

Exemplo 4: polinômios. Em P2P_2P2​, seja B=(1,  t+1,  t2)B = (1,\; t + 1,\; t^2)B=(1,t+1,t2). Ache [p]B[p]_B[p]B​ para p(t)=3+2tp(t) = 3 + 2tp(t)=3+2t:

3+2t=a⋅1+b(t+1)+c t2=(a+b)+bt+ct23 + 2t = a \cdot 1 + b(t + 1) + c\,t^2 = (a + b) + bt + ct^23+2t=a⋅1+b(t+1)+ct2=(a+b)+bt+ct2. Comparando: b=2b = 2b=2, a+b=3⇒a=1a + b = 3 \Rightarrow a = 1a+b=3⇒a=1, c=0c = 0c=0. Então [p]B=(1,2,0)[p]_B = (1, 2, 0)[p]B​=(1,2,0).

Exemplo 5: matrizes. Em M(2,2)M(2,2)M(2,2), seja

e A=[2103]A = \begin{bmatrix} 2 & 1 \\ 0 & 3 \end{bmatrix}A=[20​13​]. Escrevendo A=aB1+bB2+cB3+dB4A = a B_1 + b B_2 + c B_3 + d B_4A=aB1​+bB2​+cB3​+dB4​ e igualando entrada por entrada:

{a+b+c+d=2(entrada 1,1)b+c+d=1(1,2)c+d=0(2,1)d=3(2,2) \begin{cases} a + b + c + d = 2 & (\text{entrada } 1,1) \\ b + c + d = 1 & (1,2) \\ c + d = 0 & (2,1) \\ d = 3 & (2,2) \end{cases} ⎩⎨⎧​a+b+c+d=2b+c+d=1c+d=0d=3​(entrada 1,1)(1,2)(2,1)(2,2)​

De baixo para cima: d=3d = 3d=3, c=−3c = -3c=−3, b=1b = 1b=1, a=1a = 1a=1. Então [A]B=(1,1,−3,3)[A]_B = (1, 1, -3, 3)[A]B​=(1,1,−3,3).

Exemplo 6: simétricas. O espaço S2S_2S2​ das matrizes simétricas 2×22 \times 22×2 tem base α=([1000],[0110],[0001])\alpha = \left(\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}, \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}, \begin{bmatrix} 0 & 0 \\ 0 & 1 \end{bmatrix}\right)α=([10​00​],[01​10​],[00​01​]), de dimensão 3. Para [abbd]\begin{bmatrix} a & b \\ b & d \end{bmatrix}[ab​bd​], as coordenadas são (a,b,d)(a, b, d)(a,b,d).

Por que coordenadas importam

Escolhida uma base BBB de VVV (com dim⁡V=n\dim V = ndimV=n), a operação “pegar as coordenadas” respeita soma e esticar:

[u+v]B=[u]B+[v]Be[αv]B=α [v]B. [u + v]_B = [u]_B + [v]_B \qquad\text{e}\qquad [\alpha v]_B = \alpha\,[v]_B. [u+v]B​=[u]B​+[v]B​e[αv]B​=α[v]B​.

Isso significa que qualquer espaço de dimensão nnn se comporta como Rn\mathbb{R}^nRn. Questões sobre polinômios ou matrizes podem ser resolvidas nas coordenadas, com as contas que você já conhece (escalonamento, determinantes). Essa é a justificativa para o truque “traduza para lista” que usamos o estágio inteiro.

Mudança de base

Agora a pergunta central: se eu conheço as coordenadas de vvv numa base BBB, como descubro as coordenadas dele em outra base CCC?

A resposta é uma matriz, a matriz de mudança de base de BBB para CCC, que vamos escrever como MB→CM_{B \to C}MB→C​:

[v]C=MB→C [v]B. [v]_C = M_{B \to C}\,[v]_B. [v]C​=MB→C​[v]B​.

Pense nela como um tradutor: entra o endereço na língua BBB, sai o endereço na língua CCC.

Atenção

A notação muda de livro para livro e de professor para professor. Você vai ver [I]BC[I]_B^C[I]BC​, [I]BC[I]_{BC}[I]BC​, PB→CP_{B \to C}PB→C​ e outras, e a posição dos índices (em cima ou embaixo) não é padronizada. Não decore a notação: confira o sentido pelo exemplo do enunciado. Se a matriz dada, multiplicada por [v]β[v]_\beta[v]β​, deve resultar em [v]α[v]_\alpha[v]α​, ela leva β\betaβ para α\alphaα. Se o enunciado dá a matriz no sentido contrário ao que você quer, use a inversa.

Como montar a matriz

Se B=(b1,…,bn)B = (b_1, \ldots, b_n)B=(b1​,…,bn​), as colunas de MB→CM_{B \to C}MB→C​ são as coordenadas dos vetores de BBB escritas na base CCC:

MB→C=[  [b1]C    [b2]C    ⋯    [bn]C  ]. M_{B \to C} = \Big[\; [b_1]_C \;\; [b_2]_C \;\; \cdots \;\; [b_n]_C \;\Big]. MB→C​=[[b1​]C​[b2​]C​⋯[bn​]C​].

Em palavras: pegue cada vetor da base de partida, descubra o endereço dele na base de chegada, e coloque como coluna.

Por que funciona? Se [v]B=(a1,…,an)[v]_B = (a_1, \ldots, a_n)[v]B​=(a1​,…,an​), então v=a1b1+⋯+anbnv = a_1 b_1 + \cdots + a_n b_nv=a1​b1​+⋯+an​bn​. Tirando as coordenadas na base CCC dos dois lados e usando que elas respeitam soma e esticar:

[v]C=a1[b1]C+⋯+an[bn]C=MB→C[a1⋮an]. [v]_C = a_1 [b_1]_C + \cdots + a_n [b_n]_C = M_{B \to C} \begin{bmatrix} a_1 \\ \vdots \\ a_n \end{bmatrix}. [v]C​=a1​[b1​]C​+⋯+an​[bn​]C​=MB→C​​a1​⋮an​​​.

Exemplo 7. Em R2\mathbb{R}^2R2, BBB é a base canônica e C=((1,1),(1,−1))C = ((1, 1), (1, -1))C=((1,1),(1,−1)). Escrevemos os vetores de BBB na base CCC:

(1,0)=12(1,1)+12(1,−1)e(0,1)=12(1,1)−12(1,−1). (1, 0) = \tfrac{1}{2}(1, 1) + \tfrac{1}{2}(1, -1) \qquad\text{e}\qquad (0, 1) = \tfrac{1}{2}(1, 1) - \tfrac{1}{2}(1, -1). (1,0)=21​(1,1)+21​(1,−1)e(0,1)=21​(1,1)−21​(1,−1).

Então

MB→C=[1/21/21/2−1/2]. M_{B \to C} = \begin{bmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{bmatrix}. MB→C​=[1/21/2​1/2−1/2​].

Teste com v=(5,1)v = (5, 1)v=(5,1), que tem [v]B=(5,1)[v]_B = (5, 1)[v]B​=(5,1):

[v]C=[1/21/21/2−1/2][51]=[32], [v]_C = \begin{bmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{bmatrix} \begin{bmatrix} 5 \\ 1 \end{bmatrix} = \begin{bmatrix} 3 \\ 2 \end{bmatrix}, [v]C​=[1/21/2​1/2−1/2​][51​]=[32​],

exatamente o que achamos no Exemplo 1. ✓

Atalho quando uma das bases é a canônica

  • Da base CCC para a canônica: as colunas são os próprios vetores de CCC, porque um vetor já está escrito na canônica. Nenhuma conta.
  • Da canônica para a base CCC: é a inversa da matriz anterior.

No Exemplo 7, MC→B=[111−1]M_{C \to B} = \begin{bmatrix} 1 & 1 \\ 1 & -1 \end{bmatrix}MC→B​=[11​1−1​], e de fato

[1/21/21/2−1/2][111−1]=[1001].  ✓ \begin{bmatrix} 1/2 & 1/2 \\ 1/2 & -1/2 \end{bmatrix} \begin{bmatrix} 1 & 1 \\ 1 & -1 \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}. \;✓ [1/21/2​1/2−1/2​][11​1−1​]=[10​01​].✓

O sentido contrário: use a inversa

A matriz de CCC para BBB desfaz a de BBB para CCC:

MC→B=(MB→C)−1. M_{C \to B} = (M_{B \to C})^{-1}. MC→B​=(MB→C​)−1.

Se for só uma conta numérica (poucas coordenadas), muitas vezes é mais rápido resolver o sistema do que inverter.

Exemplo 8. O enunciado dá M=[1201]M = \begin{bmatrix} 1 & 2 \\ 0 & 1 \end{bmatrix}M=[10​21​], que leva α\alphaα para β\betaβ (isto é, [v]β=M[v]α[v]_\beta = M[v]_\alpha[v]β​=M[v]α​), e [v]β=(5,3)[v]_\beta = (5, 3)[v]β​=(5,3). Quanto vale [v]α[v]_\alpha[v]α​?

Precisamos do sentido contrário. Em vez de inverter, resolva M[v]α=(5,3)M[v]_\alpha = (5, 3)M[v]α​=(5,3): com [v]α=(a,b)[v]_\alpha = (a, b)[v]α​=(a,b), a+2b=5a + 2b = 5a+2b=5 e b=3b = 3b=3, então a=−1a = -1a=−1. Logo [v]α=(−1,3)[v]_\alpha = (-1, 3)[v]α​=(−1,3). (Com a inversa [1−201]\begin{bmatrix} 1 & -2 \\ 0 & 1 \end{bmatrix}[10​−21​] dá o mesmo.)

Entre duas bases quaisquer

Quando nenhuma das bases é a canônica, existe um método direto: escalonar a matriz aumentada

[  C  ∣  B  ]  ⟶  [  I  ∣  MB→C  ], \big[\; C \;\big|\; B \;\big] \;\longrightarrow\; \big[\; I \;\big|\; M_{B \to C} \;\big], [C​B]⟶[I​MB→C​],

em que CCC e BBB são as matrizes com os vetores das bases nas colunas. É o mesmo método da inversa.

Logo MB→C=[10−11]M_{B \to C} = \begin{bmatrix} 1 & 0 \\ -1 & 1 \end{bmatrix}MB→C​=[1−1​01​].

Teste com v=(3,2)v = (3, 2)v=(3,2). Na base BBB: a(1,0)+b(1,1)=(3,2)a(1,0) + b(1,1) = (3,2)a(1,0)+b(1,1)=(3,2) dá b=2b = 2b=2 e a=1a = 1a=1, então [v]B=(1,2)[v]_B = (1, 2)[v]B​=(1,2). Aplicando a matriz: [v]C=(1,−1+2)=(1,1)[v]_C = (1, -1 + 2) = (1, 1)[v]C​=(1,−1+2)=(1,1). Confira: 1(2,1)+1(1,1)=(3,2)1(2,1) + 1(1,1) = (3, 2)1(2,1)+1(1,1)=(3,2). ✓

Mudando por etapas

Se você sabe ir de BBB para CCC e de CCC para DDD, vai de BBB para DDD multiplicando, com a primeira etapa à direita:

MB→D=MC→D MB→C. M_{B \to D} = M_{C \to D}\,M_{B \to C}. MB→D​=MC→D​MB→C​.

Isso é útil quando a canônica serve de ponte: MB→C=Mcan→C MB→canM_{B \to C} = M_{\text{can} \to C}\,M_{B \to \text{can}}MB→C​=Mcan→C​MB→can​.

Descobrindo uma base a partir da matriz

Se você sabe Mα→βM_{\alpha \to \beta}Mα→β​ e β\betaβ, e quer α\alphaα: as colunas da matriz são os vetores de α\alphaα escritos na base β\betaβ. Basta “desfazer” as coordenadas.

  • 2º vetor de α\alphaα: coordenadas (1,3)(1, 3)(1,3), logo 1(1,1)+3(0,2)=(1,7)1(1,1) + 3(0,2) = (1, 7)1(1,1)+3(0,2)=(1,7).

Então α=((2,2),(1,7))\alpha = ((2, 2), (1, 7))α=((2,2),(1,7)).

Em R2\mathbb{R}^2R2, B=((1,1),(1,−1))B = ((1, 1), (1, -1))B=((1,1),(1,−1)). Quanto vale [(5,1)]B[(5, 1)]_B[(5,1)]B​?

3(1,1)+2(1,−1)=(5,1)3(1,1) + 2(1,-1) = (5, 1)3(1,1)+2(1,−1)=(5,1). As coordenadas na base BBB são (3,2)(3, 2)(3,2).

As colunas de MB→CM_{B \to C}MB→C​ são…

Cada coluna é o endereço, na base de chegada (CCC), de um vetor da base de partida (BBB).

Se MB→CM_{B \to C}MB→C​ é conhecida e você precisa de MC→BM_{C \to B}MC→B​, basta…

Ir e voltar desfaz uma mudança com a outra, então as duas são inversas uma da outra.

Qual é a dimensão de M(2,2)M(2,2)M(2,2), e quantas coordenadas tem uma matriz em uma base de M(2,2)M(2,2)M(2,2)?

dim⁡M(2,2)=4\dim M(2,2) = 4dimM(2,2)=4, então qualquer base tem 4 matrizes e o vetor coordenado tem 4 números.
