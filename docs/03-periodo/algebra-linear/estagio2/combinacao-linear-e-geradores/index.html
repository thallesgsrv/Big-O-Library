Sobre

Imagine que você tem dois vetores e só pode fazer duas coisas com eles: esticar e somar. A pergunta desta página é: que vetores dá para fabricar assim?

A resposta chama-se subespaço gerado, e a pergunta “este vetor dá para fabricar?” vira, em toda questão, a mesma coisa: montar e resolver um sistema linear.

Combinação linear

Uma combinação linear de v1,v2,…,vnv_1, v_2, \ldots, v_nv1​,v2​,…,vn​ é qualquer vetor da forma

a1v1+a2v2+⋯+anvn, a_1 v_1 + a_2 v_2 + \cdots + a_n v_n, a1​v1​+a2​v2​+⋯+an​vn​,

em que a1,…,ana_1, \ldots, a_na1​,…,an​ são números reais (os coeficientes). É uma “receita”: a1a_1a1​ porções de v1v_1v1​, a2a_2a2​ porções de v2v_2v2​, e assim por diante. Os coeficientes podem ser negativos (porção negativa é andar no sentido contrário) e podem ser zero.

Exemplo 1. O vetor (5,5)(5, 5)(5,5) é combinação linear de (1,2)(1, 2)(1,2) e (3,1)(3, 1)(3,1), porque

2⋅(1,2)+1⋅(3,1)=(2+3,  4+1)=(5,5). 2 \cdot (1, 2) + 1 \cdot (3, 1) = (2 + 3,\; 4 + 1) = (5, 5). 2⋅(1,2)+1⋅(3,1)=(2+3,4+1)=(5,5).

A pergunta de todo exercício

“vvv é combinação linear de u1,…,unu_1, \ldots, u_nu1​,…,un​?” significa: existem números a1,…,ana_1, \ldots, a_na1​,…,an​ com v=a1u1+⋯+anunv = a_1u_1 + \cdots + a_nu_nv=a1​u1​+⋯+an​un​?

Os aia_iai​ são as incógnitas. Igualando as coordenadas, sai um sistema linear. Se o sistema tem solução, a resposta é sim (e a solução são os coeficientes). Se é impossível, a resposta é não.

Exemplo 2: com solução. Escreva v=(4,−1,7)v = (4, -1, 7)v=(4,−1,7) como combinação linear de u1=(1,0,0)u_1 = (1, 0, 0)u1​=(1,0,0), u2=(1,1,0)u_2 = (1, 1, 0)u2​=(1,1,0) e u3=(1,2,1)u_3 = (1, 2, 1)u3​=(1,2,1).

Queremos a,b,ca, b, ca,b,c com a(1,0,0)+b(1,1,0)+c(1,2,1)=(4,−1,7)a(1,0,0) + b(1,1,0) + c(1,2,1) = (4, -1, 7)a(1,0,0)+b(1,1,0)+c(1,2,1)=(4,−1,7). Coordenada por coordenada:

{a+b+c=4b+2c=−1c=7 \begin{cases} a + b + c = 4 \\ b + 2c = -1 \\ c = 7 \end{cases} ⎩⎨⎧​a+b+c=4b+2c=−1c=7​

Este sistema já está escalonado, então resolve de baixo para cima: c=7c = 7c=7, depois b=−1−14=−15b = -1 - 14 = -15b=−1−14=−15, depois a=4+15−7=12a = 4 + 15 - 7 = 12a=4+15−7=12. Conferindo:

12(1,0,0)−15(1,1,0)+7(1,2,1)=(12−15+7,  −15+14,  7)=(4,−1,7).  ✓ 12(1,0,0) - 15(1,1,0) + 7(1,2,1) = (12 - 15 + 7,\; -15 + 14,\; 7) = (4, -1, 7). \;✓ 12(1,0,0)−15(1,1,0)+7(1,2,1)=(12−15+7,−15+14,7)=(4,−1,7).✓

Dica

Sempre que der, confira a resposta substituindo os coeficientes na combinação. Leva 20 segundos e evita perder a questão por um erro de sinal.

Mostrar que NÃO é combinação linear

Mostrar que vvv não é combinação linear é mostrar que o sistema é impossível. Isso costuma acontecer quando há mais equações do que incógnitas.

Exemplo 3. Mostre que w=(3,4,5)w = (3, 4, 5)w=(3,4,5) não é combinação linear de v1=(1,2,0)v_1 = (1, 2, 0)v1​=(1,2,0) e v2=(2,1,3)v_2 = (2, 1, 3)v2​=(2,1,3).

Supondo av1+bv2=wa v_1 + b v_2 = wav1​+bv2​=w, temos três equações e duas incógnitas:

{a+2b=32a+b=43b=5 \begin{cases} a + 2b = 3 \\ 2a + b = 4 \\ 3b = 5 \end{cases} ⎩⎨⎧​a+2b=32a+b=43b=5​

Método: resolva duas equações e teste o resultado na que sobrou.

Das duas primeiras: a=3−2ba = 3 - 2ba=3−2b, então 2(3−2b)+b=42(3 - 2b) + b = 42(3−2b)+b=4, ou seja, 6−3b=46 - 3b = 46−3b=4, logo b=2/3b = 2/3b=2/3 e a=5/3a = 5/3a=5/3.

Testando na terceira: 3b=3⋅23=23b = 3 \cdot \tfrac{2}{3} = 23b=3⋅32​=2, mas ela exige 555. Como 2≠52 \neq 52=5, o sistema é impossível: www não é combinação linear de v1v_1v1​ e v2v_2v2​. ∎

Uma forma equivalente de ver a mesma coisa: com a=53a = \tfrac53a=35​ e b=23b = \tfrac23b=32​, a combinação dá 53v1+23v2=(3,4,2)\tfrac53 v_1 + \tfrac23 v_2 = (3, 4, 2)35​v1​+32​v2​=(3,4,2). As duas primeiras coordenadas batem com www e a terceira não (2≠52 \neq 52=5).

Nota

Qualquer par de equações serve para começar. Se você usar outro par e achar outros valores de aaa e bbb, não é erro. É justamente o sintoma de sistema impossível: cada par tem a sua solução, mas nenhuma serve para as três. Se o sistema tivesse solução, qualquer par daria os mesmos valores.

Pelo escalonamento. A matriz aumentada do sistema acima é [123214035]\left[\begin{array}{cc|c} 1 & 2 & 3 \\ 2 & 1 & 4 \\ 0 & 3 & 5 \end{array}\right]​120​213​345​​. Depois de escalonar, aparece uma linha da forma [00nuˊmero≠0]\left[\begin{array}{cc|c} 0 & 0 & \text{número} \neq 0 \end{array}\right][0​0​nuˊmero=0​]. Esse é o sinal de sistema impossível, e é o que você escreve na justificativa.

Intuição. Dois vetores que não são paralelos geram, em R3\mathbb{R}^3R3, um plano pela origem. “Combinação linear” é estar em cima desse plano. O vetor www está fora dele, então nenhuma receita chega lá.

A condição para pertencer ao gerado

Uma variação comum é: “determine uma condição em xxx, yyy e zzz para que (x,y,z)(x, y, z)(x,y,z) seja combinação linear de v1v_1v1​ e v2v_2v2​”. É o mesmo exercício, com letras no lado direito do sistema. Em vez de testar um vetor, você descobre todos os que passam.

Exemplo 4. Com v1=(1,2,0)v_1 = (1, 2, 0)v1​=(1,2,0) e v2=(2,1,3)v_2 = (2, 1, 3)v2​=(2,1,3): quando (x,y,z)=av1+bv2(x, y, z) = a v_1 + b v_2(x,y,z)=av1​+bv2​?

{a+2b=x2a+b=y3b=z \begin{cases} a + 2b = x \\ 2a + b = y \\ 3b = z \end{cases} ⎩⎨⎧​a+2b=x2a+b=y3b=z​

Resolva duas equações em função de x,y,zx, y, zx,y,z e exija que a restante funcione. Da terceira, b=z/3b = z/3b=z/3. Da primeira, a=x−2z/3a = x - 2z/3a=x−2z/3. Substituindo na segunda:

2(x−2z3)+z3=y  ⟹  2x−4z3+z3=y  ⟹  2x−z=y. 2\left(x - \tfrac{2z}{3}\right) + \tfrac{z}{3} = y \;\Longrightarrow\; 2x - \tfrac{4z}{3} + \tfrac{z}{3} = y \;\Longrightarrow\; 2x - z = y. 2(x−32z​)+3z​=y⟹2x−34z​+3z​=y⟹2x−z=y.

A condição é 2x−y−z=02x - y - z = 02x−y−z=0. Isso é a equação do plano gerado por v1v_1v1​ e v2v_2v2​.

Conferindo: v1=(1,2,0)v_1 = (1, 2, 0)v1​=(1,2,0) dá 2−2−0=02 - 2 - 0 = 02−2−0=0 ✓; v2=(2,1,3)v_2 = (2, 1, 3)v2​=(2,1,3) dá 4−1−3=04 - 1 - 3 = 04−1−3=0 ✓; e w=(3,4,5)w = (3, 4, 5)w=(3,4,5) dá 6−4−5=−3≠06 - 4 - 5 = -3 \neq 06−4−5=−3=0, de acordo com o Exemplo 3. ✓

Dica

Escalonando, a condição aparece sozinha. Escalone a matriz aumentada com x,y,zx, y, zx,y,z na última coluna. A linha que fica [0    0∣expressa˜o em x,y,z]\left[0 \;\; 0 \mid \text{expressão em } x,y,z\right][00∣expressa˜o em x,y,z] dá a condição: expressão = 0.

Descobrindo um valor desconhecido

Se o vetor tem um parâmetro kkk, basta aplicar a condição. Por exemplo, para que (3,k,2)(3, k, 2)(3,k,2) seja combinação linear de v1v_1v1​ e v2v_2v2​, é preciso 2⋅3−k−2=02 \cdot 3 - k - 2 = 02⋅3−k−2=0, ou seja, k=4k = 4k=4. Conferindo: b=2/3b = 2/3b=2/3, a=3−4/3=5/3a = 3 - 4/3 = 5/3a=3−4/3=5/3, e 2a+b=10/3+2/3=4=k2a + b = 10/3 + 2/3 = 4 = k2a+b=10/3+2/3=4=k. ✓

Polinômios e matrizes: traduza para lista

Nada de novo: iguale os coeficientes. Dois polinômios são iguais quando têm os mesmos coeficientes em cada potência de ttt. Duas matrizes são iguais quando têm as mesmas entradas.

Exemplo 5. O polinômio p(t)=2+3t+5t2p(t) = 2 + 3t + 5t^2p(t)=2+3t+5t2 pertence ao gerado por 1+t1 + t1+t, t+t2t + t^2t+t2 e 1+t21 + t^21+t2?

Queremos a(1+t)+b(t+t2)+c(1+t2)=2+3t+5t2a(1 + t) + b(t + t^2) + c(1 + t^2) = 2 + 3t + 5t^2a(1+t)+b(t+t2)+c(1+t2)=2+3t+5t2. Agrupando o lado esquerdo por potência, fica (a+c)+(a+b)t+(b+c)t2(a + c) + (a + b)t + (b + c)t^2(a+c)+(a+b)t+(b+c)t2. Comparando:

{a+c=2a+b=3b+c=5 \begin{cases} a + c = 2 \\ a + b = 3 \\ b + c = 5 \end{cases} ⎩⎨⎧​a+c=2a+b=3b+c=5​

Somando as três: 2(a+b+c)=102(a + b + c) = 102(a+b+c)=10, então a+b+c=5a + b + c = 5a+b+c=5. Subtraindo cada equação desta, b=3b = 3b=3, c=2c = 2c=2 e a=0a = 0a=0. Conferindo: 0+3(t+t2)+2(1+t2)=2+3t+5t20 + 3(t + t^2) + 2(1 + t^2) = 2 + 3t + 5t^20+3(t+t2)+2(1+t2)=2+3t+5t2. ✓ Sim, pertence.

Exemplo 6: matrizes. [3110]\begin{bmatrix} 3 & 1 \\ 1 & 0 \end{bmatrix}[31​10​] é combinação linear de [1000]\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}[10​00​] e [0110]\begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}[01​10​]? Sim: 3[1000]+1[0110]3 \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix} + 1 \begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}3[10​00​]+1[01​10​]. Já [1200]\begin{bmatrix} 1 & 2 \\ 0 & 0 \end{bmatrix}[10​20​] não é, porque as entradas (1,2)(1,2)(1,2) e (2,1)(2,1)(2,1) precisariam ser iguais.

O subespaço gerado

O conjunto de todas as combinações lineares de v1,…,vnv_1, \ldots, v_nv1​,…,vn​ chama-se subespaço gerado por eles, e se escreve [v1,…,vn][v_1, \ldots, v_n][v1​,…,vn​]:

[v1,…,vn]={ a1v1+⋯+anvn  ∣  ai∈R }. [v_1, \ldots, v_n] = \{\, a_1v_1 + \cdots + a_nv_n \;\mid\; a_i \in \mathbb{R} \,\}. [v1​,…,vn​]={a1​v1​+⋯+an​vn​∣ai​∈R}.

Ele é sempre um subespaço (a soma de duas combinações é uma combinação e o escalar também), e é o menor subespaço que contém os viv_ivi​.

Em R3\mathbb{R}^3R3:

  • [v][v][v], com v≠0v \neq 0v=0, é uma reta pela origem;
  • [v1,v2][v_1, v_2][v1​,v2​], com v1,v2v_1, v_2v1​,v2​ não paralelos, é um plano pela origem;
  • três vetores “independentes” geram R3\mathbb{R}^3R3 inteiro.

Por exemplo, o plano z=x+yz = x + yz=x+y em R3\mathbb{R}^3R3 é gerado por (1,0,1)(1, 0, 1)(1,0,1) e (0,1,1)(0, 1, 1)(0,1,1).

Atenção

Dois vetores nunca geram R3\mathbb{R}^3R3. No máximo geram um plano. Para gerar R3\mathbb{R}^3R3 são necessários pelo menos 3 vetores. Isso responde rápido a perguntas do tipo “todo vetor de R3\mathbb{R}^3R3 é combinação linear destes dois?” (a resposta é não).

Conjunto gerador

Dizemos que {v1,…,vn}\{v_1, \ldots, v_n\}{v1​,…,vn​} gera o espaço VVV (ou que é um conjunto gerador de VVV) quando [v1,…,vn]=V[v_1, \ldots, v_n] = V[v1​,…,vn​]=V. Para provar, é preciso mostrar que todo vetor de VVV é combinação linear de v1,…,vnv_1, \ldots, v_nv1​,…,vn​. Isso se faz com um vetor genérico.

Exemplo 7. Mostre que P2=[1+t,  1−t,  t2]P_2 = [1 + t,\; 1 - t,\; t^2]P2​=[1+t,1−t,t2].

Seja p(t)=a+bt+ct2p(t) = a + bt + ct^2p(t)=a+bt+ct2 um polinômio qualquer de P2P_2P2​. Queremos x,y,zx, y, zx,y,z com

a+bt+ct2=x(1+t)+y(1−t)+zt2=(x+y)+(x−y)t+zt2. a + bt + ct^2 = x(1 + t) + y(1 - t) + zt^2 = (x + y) + (x - y)t + zt^2. a+bt+ct2=x(1+t)+y(1−t)+zt2=(x+y)+(x−y)t+zt2.

Comparando coeficientes: x+y=ax + y = ax+y=a, x−y=bx - y = bx−y=b, z=cz = cz=c. Somando as duas primeiras, 2x=a+b2x = a + b2x=a+b; subtraindo, 2y=a−b2y = a - b2y=a−b. Então

x=a+b2,y=a−b2,z=c. x = \frac{a + b}{2}, \qquad y = \frac{a - b}{2}, \qquad z = c. x=2a+b​,y=2a−b​,z=c.

Para qualquer a,b,ca, b, ca,b,c existe solução, então todo polinômio de P2P_2P2​ é combinação desses três. ∎

Aplicando a fórmula a p(t)=2−t+3t2p(t) = 2 - t + 3t^2p(t)=2−t+3t2 (a=2a = 2a=2, b=−1b = -1b=−1, c=3c = 3c=3) sai x=12x = \tfrac12x=21​, y=32y = \tfrac32y=23​, z=3z = 3z=3, ou seja, 2−t+3t2=12(1+t)+32(1−t)+3t22 - t + 3t^2 = \tfrac12(1 + t) + \tfrac32(1 - t) + 3t^22−t+3t2=21​(1+t)+23​(1−t)+3t2.

Nota

Dá para provar o mesmo por outro caminho: se os três polinômios forem LI e dim⁡P2=3\dim P_2 = 3dimP2​=3, eles formam uma base, e toda base gera o espaço (veja as páginas seguintes). Os dois caminhos valem.

A habilidade mais cobrada: achar geradores

Quando o subespaço vem por equações, a pergunta “ache geradores” tem uma receita fixa: isole as variáveis e separe por variável livre.

Exemplo 8. W={(x,y,z)∈R3∣x+2y−z=0}W = \{(x, y, z) \in \mathbb{R}^3 \mid x + 2y - z = 0\}W={(x,y,z)∈R3∣x+2y−z=0}.

  1. A equação diz z=x+2yz = x + 2yz=x+2y. As variáveis xxx e yyy são livres (podem ter qualquer valor) e zzz é determinada.
  2. Todo vetor de WWW é (x,y,x+2y)(x, y, x + 2y)(x,y,x+2y).
  3. Separe uma parcela por variável livre:
(x,y,x+2y)=x (1,0,1)+y (0,1,2). (x, y, x + 2y) = x\,(1, 0, 1) + y\,(0, 1, 2). (x,y,x+2y)=x(1,0,1)+y(0,1,2).

Então W=[(1,0,1),(0,1,2)]W = [(1, 0, 1), (0, 1, 2)]W=[(1,0,1),(0,1,2)]. Conferindo: (1,0,1)(1,0,1)(1,0,1) dá 1+0−1=01 + 0 - 1 = 01+0−1=0 ✓ e (0,1,2)(0,1,2)(0,1,2) dá 0+2−2=00 + 2 - 2 = 00+2−2=0 ✓.

Exemplo 9: duas equações. W={(x,y,z)∈R3∣x−y=0 e y+z=0}W = \{(x, y, z) \in \mathbb{R}^3 \mid x - y = 0 \text{ e } y + z = 0\}W={(x,y,z)∈R3∣x−y=0 e y+z=0}. Da primeira, x=yx = yx=y; da segunda, z=−yz = -yz=−y. Só yyy é livre:

(y,y,−y)=y (1,1,−1)⟹W=[(1,1,−1)]. (y, y, -y) = y\,(1, 1, -1) \quad\Longrightarrow\quad W = [(1, 1, -1)]. (y,y,−y)=y(1,1,−1)⟹W=[(1,1,−1)].

Exemplo 10: matrizes simétricas. [abbd]=a[1000]+b[0110]+d[0001]\begin{bmatrix} a & b \\ b & d \end{bmatrix} = a\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix} + b\begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix} + d\begin{bmatrix} 0 & 0 \\ 0 & 1 \end{bmatrix}[ab​bd​]=a[10​00​]+b[01​10​]+d[00​01​]. Os três do lado direito geram as simétricas 2×22 \times 22×2.

Dica

O número de geradores obtidos por esse método é o número de variáveis livres (no Exemplo 8, 2; no Exemplo 9, 1). Esse mesmo número será a dimensão do subespaço, na página de Base e Dimensão.
