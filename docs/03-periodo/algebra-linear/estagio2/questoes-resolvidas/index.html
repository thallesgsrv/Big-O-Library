Sobre

Esta página reúne exercícios completos do Estágio 2, agrupados por tipo e resolvidos passo a passo. Cada seção aponta a página onde a teoria está explicada com calma.

Como usar: tente cada questão sozinho primeiro e só abra a resolução depois. Se travar, as receitas resumidas estão na Revisão Relâmpago.

Dica

Nas questões de V ou F, a justificativa faz parte da resposta. Escrever só “V” ou “F” não vale nada: mostre a conta, o contraexemplo ou a propriedade que decide.

1. É subespaço? (V ou F)

Teoria: Subespaços. A pergunta de sempre: o filtro é uma equação linear igual a zero, ou tem produto, quadrado, desigualdade ou número solto?

Questão 1. U={(x,y,z,t)∈R4∣t=xz}U = \{(x, y, z, t) \in \mathbb{R}^4 \mid t = xz\}U={(x,y,z,t)∈R4∣t=xz} é subespaço de R4\mathbb{R}^4R4?

Resolução

Passo 1: o filtro. t=xzt = xzt=xz tem um produto de variáveis. Desconfie: não é do tipo “combinação linear = 0”.

Passo 2: um elemento simples de UUU.

u=(1,0,1,1),pois t=1=1⋅1=xz. u = (1, 0, 1, 1), \quad\text{pois } t = 1 = 1 \cdot 1 = xz. u=(1,0,1,1),pois t=1=1⋅1=xz.

Passo 3: multiplicar por 2 e testar o filtro.

2u=(2,0,2,2),xz=2⋅2=4≠2=t. 2u = (2, 0, 2, 2), \qquad xz = 2 \cdot 2 = 4 \neq 2 = t. 2u=(2,0,2,2),xz=2⋅2=4=2=t.

Resposta: F. 2u∉U2u \notin U2u∈/U, então não fecha no escalar.

Questão 2. W={(x,y,z)∈R3∣z=x+3y}W = \{(x, y, z) \in \mathbb{R}^3 \mid z = x + 3y\}W={(x,y,z)∈R3∣z=x+3y} é subespaço de R3\mathbb{R}^3R3?

Resolução

Passo 1: reescrever o filtro.

z=x+3y  ⟺  x+3y−z=0. z = x + 3y \;\Longleftrightarrow\; x + 3y - z = 0. z=x+3y⟺x+3y−z=0.

É uma equação linear igual a zero.

Passo 2: provar com letras. Sejam u=(x1,y1,z1)u = (x_1, y_1, z_1)u=(x1​,y1​,z1​) e v=(x2,y2,z2)v = (x_2, y_2, z_2)v=(x2​,y2​,z2​) em WWW, com z1=x1+3y1z_1 = x_1 + 3y_1z1​=x1​+3y1​ e z2=x2+3y2z_2 = x_2 + 3y_2z2​=x2​+3y2​.

  • Zero: 0=0+3⋅00 = 0 + 3 \cdot 00=0+3⋅0. ✓
  • Soma: z1+z2=(x1+x2)+3(y1+y2)z_1 + z_2 = (x_1 + x_2) + 3(y_1 + y_2)z1​+z2​=(x1​+x2​)+3(y1​+y2​). ✓
  • Escalar: αz1=αx1+3(αy1)\alpha z_1 = \alpha x_1 + 3(\alpha y_1)αz1​=αx1​+3(αy1​). ✓

Questão 3. U={(x,y,z)∈R3∣x=y=3z}U = \{(x, y, z) \in \mathbb{R}^3 \mid x = y = 3z\}U={(x,y,z)∈R3∣x=y=3z} é subespaço de R3\mathbb{R}^3R3?

Resolução

Passo 1: reescrever o filtro. x=y=3zx = y = 3zx=y=3z são duas equações:

x−y=0ey−3z=0. x - y = 0 \qquad\text{e}\qquad y - 3z = 0. x−y=0ey−3z=0.

Passo 2: reconhecer o tipo. Ambas são lineares e iguais a zero, então UUU é subespaço (teorema do “igual a zero”).

Passo 3: ver o que ele é. (x,y,z)=(3z,3z,z)=z(3,3,1)(x, y, z) = (3z, 3z, z) = z(3, 3, 1)(x,y,z)=(3z,3z,z)=z(3,3,1): uma reta pela origem.

Resposta: V.

Questão 4. W={(x,y,z)∈R3∣z=x2+y}W = \{(x, y, z) \in \mathbb{R}^3 \mid z = x^2 + y\}W={(x,y,z)∈R3∣z=x2+y} é subespaço de R3\mathbb{R}^3R3?

Resolução

Passo 1: o filtro. z=x2+yz = x^2 + yz=x2+y tem um quadrado: desconfie.

Passo 2: um elemento simples de WWW.

u=(1,0,1),pois z=1=12+0. u = (1, 0, 1), \quad\text{pois } z = 1 = 1^2 + 0. u=(1,0,1),pois z=1=12+0.

Passo 3: multiplicar por 2 e testar.

2u=(2,0,2),x2+y=4+0=4≠2=z. 2u = (2, 0, 2), \qquad x^2 + y = 4 + 0 = 4 \neq 2 = z. 2u=(2,0,2),x2+y=4+0=4=2=z.

Resposta: F. Não fecha no escalar.

Questão 5. W={[abcd]∈M(2,2)  ∣  a=c e b+d=0}W = \left\{\begin{bmatrix} a & b \\ c & d \end{bmatrix} \in M(2,2) \;\mid\; a = c \text{ e } b + d = 0\right\}W={[ac​bd​]∈M(2,2)∣a=c e b+d=0} é subespaço de M(2,2)M(2,2)M(2,2)? Se for, dê uma base.

Passo 2: reconhecer o tipo. Ambas são lineares e iguais a zero, então WWW é subespaço (teorema do “igual a zero”). Com letras: se AAA e BBB estão em WWW, somar as duas igualdades de cada uma mostra que A+BA + BA+B também passa; e multiplicar por α\alphaα mantém as igualdades.

Passo 3: ver o que ele é. Com c=ac = ac=a e d=−bd = -bd=−b:

Teoria: Combinação linear, Dependência linear e Base e dimensão. Primeiro conte os vetores; depois decida entre determinante, sistema ou procurar uma relação.

Resposta: V. det⁡=1≠0\det = 1 \neq 0det=1=0, então os três são LI e formam base.

Questão 7. Passo 2: procurar uma relação. A quarta é

3. Valor de kkk

Teoria: Combinação linear (para ser combinação) e Dependência linear (para ser LD ou LI). Em combinação, resolva as equações sem kkk e deixe a que tem kkk dar o valor. Em dependência, det⁡=0\det = 0det=0.

Resolução

{a+b=5−3a+4b=k−2a−3b=−13 \begin{cases} a + b = 5 \\ -3a + 4b = k \\ -2a - 3b = -13 \end{cases} ⎩⎨⎧​a+b=5−3a+4b=k−2a−3b=−13​

Então a=2a = 2a=2.

4. Dimensão de um subespaço (parâmetros ou geradores)

Teoria: Base e dimensão, seção “Quando o subespaço vem por parâmetros”. Separe uma matriz (ou vetor) por parâmetro e procure o que sobra. Em todas as questões desta seção a resposta é 2, e não 3.
