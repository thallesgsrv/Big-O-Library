Estágio 2 - Espaços Vetoriais

O(√n) · 3º período

Do zero e sem Vetorial. Espaços, subespaços, combinação linear, base, dimensão e coordenadas.

Pode começar do zero

Você não precisa ter cursado Vetorial (Geometria Analítica) para este estágio. Tudo o que vem de lá e que você vai usar cabe em três ideias:

  1. Um vetor é só uma lista de números. (2,5)(2, 5)(2,5) é um vetor de R2\mathbb{R}^2R2 e (1,0,−3)(1, 0, -3)(1,0,−3) é um vetor de R3\mathbb{R}^3R3. Você não precisa pensar em setas, ângulos ou produto escalar. Se quiser desenhar, (2,5)(2, 5)(2,5) é o ponto que fica 2 para a direita e 5 para cima.
  2. Dá para somar listas e esticar listas. Somar é somar posição por posição: (1,2)+(3,5)=(4,7)(1, 2) + (3, 5) = (4, 7)(1,2)+(3,5)=(4,7). Esticar é multiplicar todas as posições pelo mesmo número: 3⋅(1,2)=(3,6)3 \cdot (1, 2) = (3, 6)3⋅(1,2)=(3,6).
  3. Quase tudo vira um sistema linear. Quando você travar, a pergunta mágica é: “dá para transformar isso em um sistema linear e escalonar?”. Quase sempre dá.

O resto (subespaço, base, dimensão, coordenadas) é vocabulário novo para coisas que você já sabe fazer.

Bagagem esperada

As contas que aparecem vêm quase todas do Estágio 1:

  • Escalonamento e sistemas lineares: é a ferramenta principal do estágio.
  • Determinante: serve de atalho para decidir se uma lista de vetores é independente.
  • Matrizes: somar matrizes e multiplicar uma matriz por um número. Elas viram exemplos de “vetores”.
  • Polinômios: somar dois polinômios e multiplicar um polinômio por um número.

Como ler a notação de conjuntos

Quase toda definição do estágio tem este formato:

W={ (x,y,z)∈R3  ∣  x−3z=0 } W = \{\,(x, y, z) \in \mathbb{R}^3 \;\mid\; x - 3z = 0\,\} W={(x,y,z)∈R3∣x−3z=0}

Leia da esquerda para a direita:

  • {\{{ e }\}}: “o conjunto de”.
  • (x,y,z)∈R3(x, y, z) \in \mathbb{R}^3(x,y,z)∈R3: “os vetores (x,y,z)(x, y, z)(x,y,z) que moram em R3\mathbb{R}^3R3”. Este é o espaço grande, de onde os candidatos saem.
  • A barra ∣\mid∣ (alguns livros usam dois pontos :::): lê-se “tais que”.
  • x−3z=0x - 3z = 0x−3z=0: o filtro. Só entra em WWW quem passa nesse filtro.

Então WWW é “o conjunto dos vetores de R3\mathbb{R}^3R3 tais que x−3z=0x - 3z = 0x−3z=0”. Para pertencer a WWW é preciso estar no espaço grande e passar pelo filtro. Guarde esta imagem: ela resolve metade das dúvidas das próximas páginas.

A ideia do estágio

Até aqui, cada objeto tinha a sua própria personalidade: matriz tem linhas e colunas, polinômio tem grau, par ordenado tem coordenadas. Neste estágio a gente faz o contrário e esquece o que o objeto é. Só interessa o que dá para fazer com ele:

  1. somar dois objetos do mesmo tipo;
  2. esticar (multiplicar por um número) um objeto.

Se um conjunto tem essas duas operações e elas se comportam bem, ele é um espaço vetorial, e os seus elementos passam a se chamar vetores, mesmo que sejam matrizes, polinômios ou funções. A vantagem é grande: uma teoria só vale para todos eles.

Dica

Truque que serve para o estágio inteiro. Todo objeto “esquisito” vira uma lista de números. O polinômio a+bt+ct2a + bt + ct^2a+bt+ct2 vira (a,b,c)(a, b, c)(a,b,c). A matriz [abcd]\begin{bmatrix} a & b \\ c & d \end{bmatrix}[ac​bd​] vira (a,b,c,d)(a, b, c, d)(a,b,c,d). Depois disso, é só fazer contas com listas, como em R3\mathbb{R}^3R3 ou R4\mathbb{R}^4R4.

Mapa do estágio

  1. Espaços vetoriais: a definição, as 8 regras e exemplos (e não exemplos).
  2. Subespaços: como provar que um conjunto é subespaço e como mostrar que não é.
  3. Soma de subespaços: juntar dois subespaços e a soma direta.
  4. Combinação linear e geradores: o que dá para “fabricar” a partir de alguns vetores.
  5. Dependência linear: quando um vetor é desnecessário.
  6. Base e dimensão: o menor conjunto que gera tudo, e o “tamanho” de um espaço.
  7. Coordenadas e mudança de base: o “endereço” de um vetor e como ele muda quando a base muda.
