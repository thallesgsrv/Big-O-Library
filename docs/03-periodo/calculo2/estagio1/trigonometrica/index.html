Como funciona?

Aqui o objetivo é integrar expressões feitas só de seno, cosseno, tangente e secante, como sen⁡3xcos⁡2x\operatorname{sen}^3 x\cos^2 xsen3xcos2x ou tg⁡4x\operatorname{tg}^4 xtg4x. Não existe uma fórmula única: o truque é usar identidades para cair numa substituição u=…u = \ldotsu=… simples.

Sobre

Duas identidades fazem quase todo o trabalho:

sen⁡2x+cos⁡2x=1etg⁡2x+1=sec⁡2x \operatorname{sen}^2 x + \cos^2 x = 1 \qquad\text{e}\qquad \operatorname{tg}^2 x + 1 = \sec^2 x sen2x+cos2x=1etg2x+1=sec2x

E três pares de derivadas te dizem qual substituição escolher:

Se aparece…Faça…Porque…
sen⁡x dx\operatorname{sen} x\,dxsenxdxu=cos⁡xu = \cos xu=cosxdu=−sen⁡x dxdu = -\operatorname{sen} x\,dxdu=−senxdx
cos⁡x dx\cos x\,dxcosxdxu=sen⁡xu = \operatorname{sen} xu=senxdu=cos⁡x dxdu = \cos x\,dxdu=cosxdx
sec⁡2x dx\sec^2 x\,dxsec2xdxu=tg⁡xu = \operatorname{tg} xu=tgxdu=sec⁡2x dxdu = \sec^2 x\,dxdu=sec2xdx
sec⁡xtg⁡x dx\sec x\operatorname{tg} x\,dxsecxtgxdxu=sec⁡xu = \sec xu=secxdu=sec⁡xtg⁡x dxdu = \sec x\operatorname{tg} x\,dxdu=secxtgxdx

Aquecimento

Exemplo 1. ∫tg⁡x dx\displaystyle\int \operatorname{tg} x\,dx∫tgxdx

Escreva tg⁡x=sen⁡xcos⁡x\operatorname{tg} x = \dfrac{\operatorname{sen} x}{\cos x}tgx=cosxsenx​ e faça u=cos⁡xu = \cos xu=cosx, du=−sen⁡x dxdu = -\operatorname{sen} x\,dxdu=−senxdx:

∫sen⁡xcos⁡x dx=−∫duu=−ln⁡∣cos⁡x∣+C=ln⁡∣sec⁡x∣+C \int \frac{\operatorname{sen} x}{\cos x}\,dx = -\int\frac{du}{u} = -\ln\lvert\cos x\rvert + C = \ln\lvert\sec x\rvert + C ∫cosxsenx​dx=−∫udu​=−ln∣cosx∣+C=ln∣secx∣+C

Exemplo 2. ∫sec⁡xtg⁡x dx\displaystyle\int \sec x\operatorname{tg} x\,dx∫secxtgxdx

Com u=sec⁡xu = \sec xu=secx, du=sec⁡xtg⁡x dxdu = \sec x\operatorname{tg} x\,dxdu=secxtgxdx:

∫du=sec⁡x+C \int du = \sec x + C ∫du=secx+C

Exemplo 3. ∫sec⁡x dx\displaystyle\int \sec x\,dx∫secxdx

Esta é “mágica”: multiplique e divida por sec⁡x+tg⁡x\sec x + \operatorname{tg} xsecx+tgx.

∫sec⁡x⋅sec⁡x+tg⁡xsec⁡x+tg⁡x dx=∫sec⁡2x+sec⁡xtg⁡xsec⁡x+tg⁡x dx \int \sec x\cdot\frac{\sec x + \operatorname{tg} x}{\sec x + \operatorname{tg} x}\,dx = \int \frac{\sec^2 x + \sec x\operatorname{tg} x}{\sec x + \operatorname{tg} x}\,dx ∫secx⋅secx+tgxsecx+tgx​dx=∫secx+tgxsec2x+secxtgx​dx

O numerador é exatamente a derivada do denominador. Com u=sec⁡x+tg⁡xu = \sec x + \operatorname{tg} xu=secx+tgx:

∫sec⁡x dx=ln⁡∣sec⁡x+tg⁡x∣+C \int \sec x\,dx = \ln\lvert\sec x + \operatorname{tg} x\rvert + C ∫secxdx=ln∣secx+tgx∣+C

Potências de seno e cosseno

A ideia depende dos expoentes:

  • Se um dos expoentes for ímpar: separe um fator do que tem expoente ímpar, converta o resto com sen⁡2+cos⁡2=1\operatorname{sen}^2 + \cos^2 = 1sen2+cos2=1 e faça a substituição.
  • Se os dois forem pares: use as identidades do arco duplo.
sen⁡2x=1−cos⁡2x2cos⁡2x=1+cos⁡2x2 \operatorname{sen}^2 x = \frac{1-\cos 2x}{2} \qquad\qquad \cos^2 x = \frac{1+\cos 2x}{2} sen2x=21−cos2x​cos2x=21+cos2x​

Exemplo 4. ∫sen⁡3xcos⁡2x dx\displaystyle\int \operatorname{sen}^3 x\cos^2 x\,dx∫sen3xcos2xdx

O seno tem expoente ímpar. Separe um seno: sen⁡3x=sen⁡2x⋅sen⁡x=(1−cos⁡2x)sen⁡x\operatorname{sen}^3 x = \operatorname{sen}^2 x\cdot\operatorname{sen} x = (1-\cos^2 x)\operatorname{sen} xsen3x=sen2x⋅senx=(1−cos2x)senx. Com u=cos⁡xu = \cos xu=cosx:

∫(1−u2) u2 (−du)=−u33+u55+C=−cos⁡3x3+cos⁡5x5+C \int (1-u^2)\,u^2\,(-du) = -\frac{u^3}{3} + \frac{u^5}{5} + C = -\frac{\cos^3 x}{3} + \frac{\cos^5 x}{5} + C ∫(1−u2)u2(−du)=−3u3​+5u5​+C=−3cos3x​+5cos5x​+C

Exemplo 5. ∫cos⁡5x dx\displaystyle\int \cos^5 x\,dx∫cos5xdx

cos⁡5x=(1−sen⁡2x)2cos⁡x\cos^5 x = (1-\operatorname{sen}^2 x)^2\cos xcos5x=(1−sen2x)2cosx. Com u=sen⁡xu = \operatorname{sen} xu=senx:

∫(1−u2)2 du=u−2u33+u55+C=sen⁡x−2sen⁡3x3+sen⁡5x5+C \int (1-u^2)^2\,du = u - \frac{2u^3}{3} + \frac{u^5}{5} + C = \operatorname{sen} x - \frac{2\operatorname{sen}^3 x}{3} + \frac{\operatorname{sen}^5 x}{5} + C ∫(1−u2)2du=u−32u3​+5u5​+C=senx−32sen3x​+5sen5x​+C

Exemplo 6. ∫sen⁡2x dx\displaystyle\int \operatorname{sen}^2 x\,dx∫sen2xdx

Expoente par: use o arco duplo.

∫1−cos⁡2x2 dx=x2−sen⁡2x4+C \int\frac{1-\cos 2x}{2}\,dx = \frac{x}{2} - \frac{\operatorname{sen} 2x}{4} + C ∫21−cos2x​dx=2x​−4sen2x​+C

Exemplo 7. ∫sen⁡2xcos⁡2x dx\displaystyle\int \operatorname{sen}^2 x\cos^2 x\,dx∫sen2xcos2xdx

Os dois são pares. Um atalho: sen⁡xcos⁡x=12sen⁡2x\operatorname{sen} x\cos x = \tfrac12\operatorname{sen} 2xsenxcosx=21​sen2x, então sen⁡2xcos⁡2x=14sen⁡22x=1−cos⁡4x8\operatorname{sen}^2 x\cos^2 x = \tfrac14\operatorname{sen}^2 2x = \dfrac{1-\cos 4x}{8}sen2xcos2x=41​sen22x=81−cos4x​.

∫1−cos⁡4x8 dx=x8−sen⁡4x32+C \int \frac{1-\cos 4x}{8}\,dx = \frac{x}{8} - \frac{\operatorname{sen} 4x}{32} + C ∫81−cos4x​dx=8x​−32sen4x​+C

Atenção

Cuidado com a regra da cadeia “ao contrário”: ∫cos⁡4x dx=sen⁡4x4\int \cos 4x\,dx = \dfrac{\operatorname{sen} 4x}{4}∫cos4xdx=4sen4x​, e não sen⁡4x\operatorname{sen} 4xsen4x. Sempre divida pelo coeficiente de xxx.

Eliminação de raízes

Quando há raiz de 1±cos⁡(⋅)1 \pm \cos(\cdot)1±cos(⋅), as identidades do arco duplo fazem a raiz sumir:

1−cos⁡2x=2sen⁡2x1+cos⁡2x=2cos⁡2x 1-\cos 2x = 2\operatorname{sen}^2 x \qquad\qquad 1+\cos 2x = 2\cos^2 x 1−cos2x=2sen2x1+cos2x=2cos2x

Exemplo 8. ∫1−cos⁡2x dx\displaystyle\int \sqrt{1-\cos 2x}\,dx∫1−cos2x​dx

2sen⁡2x=2 ∣sen⁡x∣\sqrt{2\operatorname{sen}^2 x} = \sqrt2\,\lvert\operatorname{sen} x\rvert2sen2x​=2​∣senx∣. Em um intervalo onde sen⁡x≥0\operatorname{sen} x \ge 0senx≥0:

2∫sen⁡x dx=−2cos⁡x+C \sqrt2\int \operatorname{sen} x\,dx = -\sqrt2\cos x + C 2​∫senxdx=−2​cosx+C

Exemplo 9. ∫1+cos⁡4x dx\displaystyle\int \sqrt{1+\cos 4x}\,dx∫1+cos4x​dx

Com 1+cos⁡4x=2cos⁡22x1+\cos 4x = 2\cos^2 2x1+cos4x=2cos22x, a raiz é 2 ∣cos⁡2x∣\sqrt2\,\lvert\cos 2x\rvert2​∣cos2x∣. Onde cos⁡2x≥0\cos 2x \ge 0cos2x≥0:

2∫cos⁡2x dx=22sen⁡2x+C \sqrt2\int\cos 2x\,dx = \frac{\sqrt2}{2}\operatorname{sen} 2x + C 2​∫cos2xdx=22​​sen2x+C

Importante

a2=∣a∣\sqrt{a^2} = \lvert a\rverta2​=∣a∣, nunca simplesmente aaa. Nos exemplos acima, assumimos o sinal do módulo; em outro intervalo, o sinal da resposta pode inverter.

Produto de senos e cossenos

Quando os ângulos são diferentes (como 3x3x3x e 5x5x5x), use as fórmulas de produto para soma:

sen⁡Asen⁡B=12[cos⁡(A−B)−cos⁡(A+B)]sen⁡Acos⁡B=12[sen⁡(A−B)+sen⁡(A+B)]cos⁡Acos⁡B=12[cos⁡(A−B)+cos⁡(A+B)] \begin{aligned} \operatorname{sen}A\operatorname{sen}B &= \tfrac12\big[\cos(A-B) - \cos(A+B)\big]\\ \operatorname{sen}A\cos B &= \tfrac12\big[\operatorname{sen}(A-B) + \operatorname{sen}(A+B)\big]\\ \cos A\cos B &= \tfrac12\big[\cos(A-B) + \cos(A+B)\big] \end{aligned} senAsenBsenAcosBcosAcosB​=21​[cos(A−B)−cos(A+B)]=21​[sen(A−B)+sen(A+B)]=21​[cos(A−B)+cos(A+B)]​

Exemplo 10. ∫sen⁡xcos⁡x dx\displaystyle\int \operatorname{sen} x\cos x\,dx∫senxcosxdx

12∫sen⁡2x dx=−cos⁡2x4+C \tfrac12\int \operatorname{sen} 2x\,dx = -\frac{\cos 2x}{4} + C 21​∫sen2xdx=−4cos2x​+C

(Outra resposta correta: 12sen⁡2x+C\tfrac12\operatorname{sen}^2 x + C21​sen2x+C, com u=sen⁡xu = \operatorname{sen} xu=senx. As duas diferem por uma constante.)

Exemplo 11. ∫cos⁡(−x)cos⁡(2x) dx\displaystyle\int \cos(-x)\cos(2x)\,dx∫cos(−x)cos(2x)dx

Como cos⁡(−x)=cos⁡x\cos(-x) = \cos xcos(−x)=cosx:

12∫[cos⁡x+cos⁡3x] dx=sen⁡x2+sen⁡3x6+C \tfrac12\int\big[\cos x + \cos 3x\big]\,dx = \frac{\operatorname{sen} x}{2} + \frac{\operatorname{sen} 3x}{6} + C 21​∫[cosx+cos3x]dx=2senx​+6sen3x​+C

Exemplo 12. ∫sen⁡(3x)cos⁡(5x) dx\displaystyle\int \operatorname{sen}(3x)\cos(5x)\,dx∫sen(3x)cos(5x)dx

Com A=3xA = 3xA=3x e B=5xB = 5xB=5x: sen⁡(−2x)+sen⁡(8x)\operatorname{sen}(-2x) + \operatorname{sen}(8x)sen(−2x)+sen(8x).

12∫[−sen⁡2x+sen⁡8x] dx=cos⁡2x4−cos⁡8x16+C \tfrac12\int\big[-\operatorname{sen} 2x + \operatorname{sen} 8x\big]\,dx = \frac{\cos 2x}{4} - \frac{\cos 8x}{16} + C 21​∫[−sen2x+sen8x]dx=4cos2x​−16cos8x​+C

Potências de tangente e secante

Use tg⁡2x=sec⁡2x−1\operatorname{tg}^2 x = \sec^2 x - 1tg2x=sec2x−1 para trocar tangentes por secantes (ou vice-versa) até sobrar um sec⁡2x dx\sec^2 x\,dxsec2xdx (para u=tg⁡xu = \operatorname{tg} xu=tgx) ou um sec⁡xtg⁡x dx\sec x\operatorname{tg} x\,dxsecxtgxdx (para u=sec⁡xu = \sec xu=secx).

Exemplo 13. ∫tg⁡4x dx\displaystyle\int \operatorname{tg}^4 x\,dx∫tg4xdx

tg⁡4x=tg⁡2x(sec⁡2x−1)=tg⁡2xsec⁡2x−tg⁡2x=tg⁡2xsec⁡2x−sec⁡2x+1 \operatorname{tg}^4 x = \operatorname{tg}^2 x(\sec^2 x - 1) = \operatorname{tg}^2 x\sec^2 x - \operatorname{tg}^2 x = \operatorname{tg}^2 x\sec^2 x - \sec^2 x + 1 tg4x=tg2x(sec2x−1)=tg2xsec2x−tg2x=tg2xsec2x−sec2x+1∫tg⁡4x dx=tg⁡3x3−tg⁡x+x+C \int \operatorname{tg}^4 x\,dx = \frac{\operatorname{tg}^3 x}{3} - \operatorname{tg} x + x + C ∫tg4xdx=3tg3x​−tgx+x+C

Exemplo 14. ∫tg⁡4xsec⁡4x dx\displaystyle\int \operatorname{tg}^4 x\sec^4 x\,dx∫tg4xsec4xdx

A secante tem expoente par. Separe sec⁡2x\sec^2 xsec2x e troque o outro por 1+tg⁡2x1 + \operatorname{tg}^2 x1+tg2x. Com u=tg⁡xu = \operatorname{tg} xu=tgx:

∫u4(1+u2) du=u55+u77+C=tg⁡5x5+tg⁡7x7+C \int u^4(1+u^2)\,du = \frac{u^5}{5} + \frac{u^7}{7} + C = \frac{\operatorname{tg}^5 x}{5} + \frac{\operatorname{tg}^7 x}{7} + C ∫u4(1+u2)du=5u5​+7u7​+C=5tg5x​+7tg7x​+C

Exemplo 15. ∫sec⁡3x dx\displaystyle\int \sec^3 x\,dx∫sec3xdx

Aqui é preciso partes. Com u=sec⁡xu = \sec xu=secx e dv=sec⁡2x dxdv = \sec^2 x\,dxdv=sec2xdx: du=sec⁡xtg⁡x dxdu = \sec x\operatorname{tg} x\,dxdu=secxtgxdx e v=tg⁡xv = \operatorname{tg} xv=tgx.

∫sec⁡3x dx=sec⁡xtg⁡x−∫sec⁡xtg⁡2x dx=sec⁡xtg⁡x−∫sec⁡3x dx+∫sec⁡x dx \int\sec^3 x\,dx = \sec x\operatorname{tg} x - \int \sec x\operatorname{tg}^2 x\,dx = \sec x\operatorname{tg} x - \int\sec^3 x\,dx + \int\sec x\,dx ∫sec3xdx=secxtgx−∫secxtg2xdx=secxtgx−∫sec3xdx+∫secxdx

A integral original aparece nos dois lados (caso circular). Chamando-a de III: 2I=sec⁡xtg⁡x+ln⁡∣sec⁡x+tg⁡x∣2I = \sec x\operatorname{tg} x + \ln\lvert\sec x + \operatorname{tg} x\rvert2I=secxtgx+ln∣secx+tgx∣, ou seja:

∫sec⁡3x dx=12(sec⁡xtg⁡x+ln⁡∣sec⁡x+tg⁡x∣)+C \int \sec^3 x\,dx = \tfrac12\Big(\sec x\operatorname{tg} x + \ln\lvert\sec x + \operatorname{tg} x\rvert\Big) + C ∫sec3xdx=21​(secxtgx+ln∣secx+tgx∣)+C

Exercícios propostos

Exercício 1. Calcule ∫cos⁡3x dx\displaystyle\int \cos^3 x\,dx∫cos3xdx.

Gabarito

cos⁡3x=(1−sen⁡2x)cos⁡x\cos^3 x = (1-\operatorname{sen}^2 x)\cos xcos3x=(1−sen2x)cosx. Com u=sen⁡xu = \operatorname{sen} xu=senx:

∫(1−u2) du=sen⁡x−sen⁡3x3+C \int (1-u^2)\,du = \operatorname{sen} x - \frac{\operatorname{sen}^3 x}{3} + C ∫(1−u2)du=senx−3sen3x​+C

Exercício 2. Calcule ∫sen⁡5x dx\displaystyle\int \operatorname{sen}^5 x\,dx∫sen5xdx.

Gabarito

sen⁡5x=(1−cos⁡2x)2sen⁡x\operatorname{sen}^5 x = (1-\cos^2 x)^2\operatorname{sen} xsen5x=(1−cos2x)2senx. Com u=cos⁡xu = \cos xu=cosx:

−∫(1−2u2+u4) du=−cos⁡x+2cos⁡3x3−cos⁡5x5+C -\int(1-2u^2+u^4)\,du = -\cos x + \frac{2\cos^3 x}{3} - \frac{\cos^5 x}{5} + C −∫(1−2u2+u4)du=−cosx+32cos3x​−5cos5x​+C

Exercício 3. Calcule ∫tg⁡2x dx\displaystyle\int \operatorname{tg}^2 x\,dx∫tg2xdx.

Gabarito

tg⁡2x=sec⁡2x−1\operatorname{tg}^2 x = \sec^2 x - 1tg2x=sec2x−1, logo

∫(sec⁡2x−1) dx=tg⁡x−x+C \int(\sec^2 x - 1)\,dx = \operatorname{tg} x - x + C ∫(sec2x−1)dx=tgx−x+C

Exercício 4. Calcule ∫tg⁡xsec⁡3x dx\displaystyle\int \operatorname{tg} x\sec^3 x\,dx∫tgxsec3xdx.

Gabarito

Separe sec⁡xtg⁡x\sec x\operatorname{tg} xsecxtgx: o integrando é sec⁡2x⋅sec⁡xtg⁡x\sec^2 x\cdot\sec x\operatorname{tg} xsec2x⋅secxtgx. Com u=sec⁡xu = \sec xu=secx:

∫u2 du=sec⁡3x3+C \int u^2\,du = \frac{\sec^3 x}{3} + C ∫u2du=3sec3x​+C

Exercício 5. Calcule ∫sen⁡(2x)cos⁡(3x) dx\displaystyle\int \operatorname{sen}(2x)\cos(3x)\,dx∫sen(2x)cos(3x)dx.

Gabarito

sen⁡Acos⁡B\operatorname{sen}A\cos BsenAcosB com A=2xA = 2xA=2x, B=3xB = 3xB=3x: 12[sen⁡(−x)+sen⁡(5x)]\tfrac12\big[\operatorname{sen}(-x) + \operatorname{sen}(5x)\big]21​[sen(−x)+sen(5x)].

12∫[−sen⁡x+sen⁡5x] dx=cos⁡x2−cos⁡5x10+C \tfrac12\int\big[-\operatorname{sen} x + \operatorname{sen} 5x\big]\,dx = \frac{\cos x}{2} - \frac{\cos 5x}{10} + C 21​∫[−senx+sen5x]dx=2cosx​−10cos5x​+C
