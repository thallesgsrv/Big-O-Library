Substituição trigonométrica

O(√n) · 3º período

Como fazer raízes de x² ± a² e a² − x² sumirem usando triângulos retângulos.

Como funciona?

Algumas integrais têm raízes que travam qualquer substituição comum, como 4+x2\sqrt{4+x^2}4+x2​ ou 1−9x2\sqrt{1-9x^2}1−9x2​. A substituição trigonométrica resolve isso com um truque: trocar xxx por uma função trigonométrica que faz a raiz desaparecer.

Sobre

A técnica é para expressões do tipo x2+a2x^2 + a^2x2+a2, a2−x2a^2 - x^2a2−x2 ou x2−a2x^2 - a^2x2−a2 (com a>0a > 0a>0 constante), geralmente dentro de uma raiz.

A pista visual vem do teorema de Pitágoras. Cada uma dessas expressões aparece como um lado de um triângulo retângulo:

ExpressãoTriânguloHipotenusaCateto 1Cateto 2
x2+a2\sqrt{x^2 + a^2}x2+a2​a2+x2=(…)2a^2 + x^2 = (\ldots)^2a2+x2=(…)2x2+a2\sqrt{x^2+a^2}x2+a2​aaaxxx
a2−x2\sqrt{a^2 - x^2}a2−x2​x2+(…)2=a2x^2 + (\ldots)^2 = a^2x2+(…)2=a2aaaxxxa2−x2\sqrt{a^2-x^2}a2−x2​
x2−a2\sqrt{x^2 - a^2}x2−a2​(…)2+a2=x2(\ldots)^2 + a^2 = x^2(…)2+a2=x2xxxaaax2−a2\sqrt{x^2-a^2}x2−a2​

Uma pergunta que ajuda: nos três casos, quem é o maior lado? É sempre a hipotenusa. Isso diz quem deve ficar “no meio” da substituição.

As três substituições

Caso 1: x2+a2x^2 + a^2x2+a2. Use x=atg⁡θx = a\operatorname{tg}\thetax=atgθ.

x2+a2=a2tg⁡2θ+a2=atg⁡2θ+1=asec⁡θ \sqrt{x^2 + a^2} = \sqrt{a^2\operatorname{tg}^2\theta + a^2} = a\sqrt{\operatorname{tg}^2\theta + 1} = a\sec\theta x2+a2​=a2tg2θ+a2​=atg2θ+1​=asecθ

com dx=asec⁡2θ dθdx = a\sec^2\theta\,d\thetadx=asec2θdθ. Triângulo: cateto oposto xxx, adjacente aaa, hipotenusa x2+a2\sqrt{x^2+a^2}x2+a2​.

Caso 2: a2−x2a^2 - x^2a2−x2. Use x=asen⁡θx = a\operatorname{sen}\thetax=asenθ.

a2−x2=a2−a2sen⁡2θ=a1−sen⁡2θ=acos⁡θ \sqrt{a^2 - x^2} = \sqrt{a^2 - a^2\operatorname{sen}^2\theta} = a\sqrt{1 - \operatorname{sen}^2\theta} = a\cos\theta a2−x2​=a2−a2sen2θ​=a1−sen2θ​=acosθ

com dx=acos⁡θ dθdx = a\cos\theta\,d\thetadx=acosθdθ. Triângulo: oposto xxx, hipotenusa aaa, adjacente a2−x2\sqrt{a^2-x^2}a2−x2​.

Caso 3: x2−a2x^2 - a^2x2−a2. Use x=asec⁡θx = a\sec\thetax=asecθ.

x2−a2=a2sec⁡2θ−a2=asec⁡2θ−1=atg⁡θ \sqrt{x^2 - a^2} = \sqrt{a^2\sec^2\theta - a^2} = a\sqrt{\sec^2\theta - 1} = a\operatorname{tg}\theta x2−a2​=a2sec2θ−a2​=asec2θ−1​=atgθ

com dx=asec⁡θtg⁡θ dθdx = a\sec\theta\operatorname{tg}\theta\,d\thetadx=asecθtgθdθ. Triângulo: hipotenusa xxx, cateto aaa junto ao ângulo, oposto x2−a2\sqrt{x^2-a^2}x2−a2​.

Dica

Regra de bolso: (variaˊvel)2+(constante)2⇒variaˊvel=constante⋅tg⁡θ(\text{variável})^2 + (\text{constante})^2 \Rightarrow \text{variável} = \text{constante}\cdot\operatorname{tg}\theta(variaˊvel)2+(constante)2⇒variaˊvel=constante⋅tgθ (constante)2−(variaˊvel)2⇒variaˊvel=constante⋅sen⁡θ(\text{constante})^2 - (\text{variável})^2 \Rightarrow \text{variável} = \text{constante}\cdot\operatorname{sen}\theta(constante)2−(variaˊvel)2⇒variaˊvel=constante⋅senθ (variaˊvel)2−(constante)2⇒variaˊvel=constante⋅sec⁡θ(\text{variável})^2 - (\text{constante})^2 \Rightarrow \text{variável} = \text{constante}\cdot\sec\theta(variaˊvel)2−(constante)2⇒variaˊvel=constante⋅secθ

Receita

  1. Identifique o caso e faça a substituição x=a (…)x = a\,(\ldots)x=a(…). Calcule também dxdxdx.
  2. Troque tudo na integral. A raiz vira uma função trigonométrica e a integral fica só em θ\thetaθ.
  3. Resolva a integral em θ\thetaθ (aqui entram as Integrais trigonométricas).
  4. Volte para xxx desenhando o triângulo retângulo: marque θ\thetaθ, preencha os lados com a substituição e leia a resposta.

Atenção

O passo 4 é o que mais cai em prova e o que mais gente esquece. Resposta em θ\thetaθ para uma integral em xxx vale zero.

Exemplos

Exemplo 1. ∫dx4+x2\displaystyle\int\frac{dx}{\sqrt{4+x^2}}∫4+x2​dx​

Caso 1 com a=2a = 2a=2: x=2tg⁡θx = 2\operatorname{tg}\thetax=2tgθ, dx=2sec⁡2θ dθdx = 2\sec^2\theta\,d\thetadx=2sec2θdθ, 4+x2=2sec⁡θ\sqrt{4+x^2} = 2\sec\theta4+x2​=2secθ.

∫2sec⁡2θ2sec⁡θ dθ=∫sec⁡θ dθ=ln⁡∣sec⁡θ+tg⁡θ∣+C \int\frac{2\sec^2\theta}{2\sec\theta}\,d\theta = \int\sec\theta\,d\theta = \ln\lvert\sec\theta + \operatorname{tg}\theta\rvert + C ∫2secθ2sec2θ​dθ=∫secθdθ=ln∣secθ+tgθ∣+C

Voltando ao triângulo (oposto xxx, adjacente 222, hipotenusa 4+x2\sqrt{4+x^2}4+x2​): tg⁡θ=x2\operatorname{tg}\theta = \dfrac{x}{2}tgθ=2x​ e sec⁡θ=4+x22\sec\theta = \dfrac{\sqrt{4+x^2}}{2}secθ=24+x2​​.

∫dx4+x2=ln⁡∣4+x2+x2∣+C \int\frac{dx}{\sqrt{4+x^2}} = \ln\left\lvert\frac{\sqrt{4+x^2} + x}{2}\right\rvert + C ∫4+x2​dx​=ln​24+x2​+x​​+C

(Como ln⁡12\ln\tfrac12ln21​ é constante, também vale escrever ln⁡(x+4+x2)+C\ln\big(x + \sqrt{4+x^2}\big) + Cln(x+4+x2​)+C.)

Exemplo 2. ∫x3x2+1 dx\displaystyle\int\frac{x^3}{x^2+1}\,dx∫x2+1x3​dx

Aqui aparece x2+1x^2 + 1x2+1 (sem raiz): x=tg⁡θx = \operatorname{tg}\thetax=tgθ, dx=sec⁡2θ dθdx = \sec^2\theta\,d\thetadx=sec2θdθ, x2+1=sec⁡2θx^2+1 = \sec^2\thetax2+1=sec2θ.

∫tg⁡3θ sec⁡2θsec⁡2θ dθ=∫tg⁡3θ dθ=∫tg⁡θ(sec⁡2θ−1) dθ=tg⁡2θ2+ln⁡∣cos⁡θ∣+C \int\frac{\operatorname{tg}^3\theta\,\sec^2\theta}{\sec^2\theta}\,d\theta = \int\operatorname{tg}^3\theta\,d\theta = \int\operatorname{tg}\theta(\sec^2\theta - 1)\,d\theta = \frac{\operatorname{tg}^2\theta}{2} + \ln\lvert\cos\theta\rvert + C ∫sec2θtg3θsec2θ​dθ=∫tg3θdθ=∫tgθ(sec2θ−1)dθ=2tg2θ​+ln∣cosθ∣+C

No triângulo (oposto xxx, adjacente 111, hipotenusa x2+1\sqrt{x^2+1}x2+1​): tg⁡θ=x\operatorname{tg}\theta = xtgθ=x e cos⁡θ=1x2+1\cos\theta = \dfrac{1}{\sqrt{x^2+1}}cosθ=x2+1​1​.

∫x3x2+1 dx=x22−12ln⁡(x2+1)+C \int\frac{x^3}{x^2+1}\,dx = \frac{x^2}{2} - \tfrac12\ln(x^2+1) + C ∫x2+1x3​dx=2x2​−21​ln(x2+1)+C

Nota

Este exemplo também sai sem trigonometria: divida x3x^3x3 por x2+1x^2+1x2+1 para obter x−xx2+1x - \dfrac{x}{x^2+1}x−x2+1x​. Sempre vale perguntar se existe um caminho mais curto.

Exemplo 3. ∫dx1−9x2\displaystyle\int\frac{dx}{\sqrt{1-9x^2}}∫1−9x2​dx​

Reescreva 1−9x2=1−(3x)21 - 9x^2 = 1 - (3x)^21−9x2=1−(3x)2. Caso 2: 3x=sen⁡θ3x = \operatorname{sen}\theta3x=senθ, isto é, x=13sen⁡θx = \tfrac13\operatorname{sen}\thetax=31​senθ, dx=13cos⁡θ dθdx = \tfrac13\cos\theta\,d\thetadx=31​cosθdθ, 1−9x2=cos⁡θ\sqrt{1-9x^2} = \cos\theta1−9x2​=cosθ.

∫13cos⁡θcos⁡θ dθ=θ3+C=arcsen⁡(3x)3+C \int\frac{\tfrac13\cos\theta}{\cos\theta}\,d\theta = \frac{\theta}{3} + C = \frac{\operatorname{arcsen}(3x)}{3} + C ∫cosθ31​cosθ​dθ=3θ​+C=3arcsen(3x)​+C

Exemplo 4. ∫ln⁡xx1−(ln⁡x)2 dx\displaystyle\int\frac{\ln x}{x\sqrt{1-(\ln x)^2}}\,dx∫x1−(lnx)2​lnx​dx

Esta parece difícil, mas é uma pegadinha: faça primeiro u=ln⁡xu = \ln xu=lnx, du=dxxdu = \dfrac{dx}{x}du=xdx​.

∫u1−u2 du \int\frac{u}{\sqrt{1-u^2}}\,du ∫1−u2​u​du

Agora w=1−u2w = 1 - u^2w=1−u2, dw=−2u dudw = -2u\,dudw=−2udu:

−12∫w−1/2 dw=−w+C⇒−1−(ln⁡x)2+C -\tfrac12\int w^{-1/2}\,dw = -\sqrt{w} + C \quad\Rightarrow\quad -\sqrt{1-(\ln x)^2} + C −21​∫w−1/2dw=−w​+C⇒−1−(lnx)2​+C

Nota

Nem toda integral com a2−u2\sqrt{a^2 - u^2}a2−u2​ precisa de substituição trigonométrica. Se o numerador tem o “u duu\,duudu” da derivada de dentro da raiz, a substituição simples resolve.

Exemplo 5. ∫dx25x2−4\displaystyle\int\frac{dx}{\sqrt{25x^2-4}}∫25x2−4​dx​

25x2−4=(5x)2−2225x^2 - 4 = (5x)^2 - 2^225x2−4=(5x)2−22. Caso 3: 5x=2sec⁡θ5x = 2\sec\theta5x=2secθ, dx=25sec⁡θtg⁡θ dθdx = \tfrac25\sec\theta\operatorname{tg}\theta\,d\thetadx=52​secθtgθdθ, 25x2−4=2tg⁡θ\sqrt{25x^2-4} = 2\operatorname{tg}\theta25x2−4​=2tgθ.

∫25sec⁡θtg⁡θ2tg⁡θ dθ=15∫sec⁡θ dθ=15ln⁡∣sec⁡θ+tg⁡θ∣+C \int\frac{\tfrac25\sec\theta\operatorname{tg}\theta}{2\operatorname{tg}\theta}\,d\theta = \frac15\int\sec\theta\,d\theta = \frac15\ln\lvert\sec\theta + \operatorname{tg}\theta\rvert + C ∫2tgθ52​secθtgθ​dθ=51​∫secθdθ=51​ln∣secθ+tgθ∣+C

Triângulo: hipotenusa 5x5x5x, cateto 222, oposto 25x2−4\sqrt{25x^2-4}25x2−4​. Então sec⁡θ=5x2\sec\theta = \dfrac{5x}{2}secθ=25x​ e tg⁡θ=25x2−42\operatorname{tg}\theta = \dfrac{\sqrt{25x^2-4}}{2}tgθ=225x2−4​​:

∫dx25x2−4=15ln⁡∣5x+25x2−42∣+C \int\frac{dx}{\sqrt{25x^2-4}} = \frac15\ln\left\lvert\frac{5x + \sqrt{25x^2-4}}{2}\right\rvert + C ∫25x2−4​dx​=51​ln​25x+25x2−4​​​+C

Exemplo 6. ∫dxx2−4x+3\displaystyle\int\frac{dx}{\sqrt{x^2-4x+3}}∫x2−4x+3​dx​

O polinômio não está na forma pronta. Complete o quadrado:

x2−4x+3=(x−2)2−1 x^2 - 4x + 3 = (x-2)^2 - 1 x2−4x+3=(x−2)2−1

Com u=x−2u = x - 2u=x−2 (du=dxdu = dxdu=dx), temos ∫duu2−1\displaystyle\int\frac{du}{\sqrt{u^2-1}}∫u2−1​du​. Caso 3 com a=1a = 1a=1: u=sec⁡θu = \sec\thetau=secθ, que leva (como no Exemplo 5) a ln⁡∣sec⁡θ+tg⁡θ∣\ln\lvert\sec\theta + \operatorname{tg}\theta\rvertln∣secθ+tgθ∣, com sec⁡θ=u\sec\theta = usecθ=u e tg⁡θ=u2−1\operatorname{tg}\theta = \sqrt{u^2-1}tgθ=u2−1​:

∫dxx2−4x+3=ln⁡∣x−2+x2−4x+3∣+C \int\frac{dx}{\sqrt{x^2-4x+3}} = \ln\left\lvert x - 2 + \sqrt{x^2-4x+3}\right\rvert + C ∫x2−4x+3​dx​=ln​x−2+x2−4x+3​​+C

Dica

Quando o radicando é um trinômio x2+bx+cx^2 + bx + cx2+bx+c, complete o quadrado antes de qualquer coisa. Ele sempre recai num dos três casos.

Exercícios propostos

Exercício 1. Calcule ∫dxx2+2x+5\displaystyle\int\frac{dx}{x^2+2x+5}∫x2+2x+5dx​.

Gabarito

Complete o quadrado: x2+2x+5=(x+1)2+4x^2+2x+5 = (x+1)^2 + 4x2+2x+5=(x+1)2+4. Com x+1=2tg⁡θx + 1 = 2\operatorname{tg}\thetax+1=2tgθ, dx=2sec⁡2θ dθdx = 2\sec^2\theta\,d\thetadx=2sec2θdθ:

∫2sec⁡2θ4sec⁡2θ dθ=θ2+C=12arctg⁡ ⁣(x+12)+C \int\frac{2\sec^2\theta}{4\sec^2\theta}\,d\theta = \frac{\theta}{2} + C = \frac12\operatorname{arctg}\!\left(\frac{x+1}{2}\right) + C ∫4sec2θ2sec2θ​dθ=2θ​+C=21​arctg(2x+1​)+C

Exercício 2. Calcule ∫9−x2 dx\displaystyle\int\sqrt{9-x^2}\,dx∫9−x2​dx.

∫9cos⁡2θ dθ=92(θ+sen⁡θcos⁡θ)+C \int 9\cos^2\theta\,d\theta = \frac92\big(\theta + \operatorname{sen}\theta\cos\theta\big) + C ∫9cos2θdθ=29​(θ+senθcosθ)+C

Triângulo: sen⁡θ=x3\operatorname{sen}\theta = \dfrac{x}{3}senθ=3x​, cos⁡θ=9−x23\cos\theta = \dfrac{\sqrt{9-x^2}}{3}cosθ=39−x2​​.

92arcsen⁡x3+x29−x2+C \frac92\operatorname{arcsen}\frac{x}{3} + \frac{x}{2}\sqrt{9-x^2} + C 29​arcsen3x​+2x​9−x2​+C
