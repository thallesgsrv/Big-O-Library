Como funciona?

Nem toda integral imprópria tem primitiva que a gente consiga escrever. Um exemplo famoso: ∫e−x2 dx\int e^{-x^2}\,dx∫e−x2dx. Mas muitas vezes não precisamos do valor, só da resposta a uma pergunta: converge ou diverge? Os testes de comparação respondem isso comparando a integral com outra que já conhecemos.

Sobre

A intuição é de sanduíche de áreas:

  • Se uma função está abaixo de outra, e a área da de cima é finita, a área da de baixo também é finita.
  • Se a de baixo tem área infinita, a de cima tem também.

As integrais de referência (as “réguas”) vêm da página anterior:

∫1+∞dxxp  converge se p>1, diverge se p≤1 \int_1^{+\infty}\frac{dx}{x^p}\ \ \text{converge se } p > 1,\ \text{diverge se } p \le 1 ∫1+∞​xpdx​  converge se p>1, diverge se p≤1

e a exponencial ∫a+∞e−kx dx\displaystyle\int_a^{+\infty}e^{-kx}\,dx∫a+∞​e−kxdx com k>0k > 0k>0, que sempre converge (primitiva −1ke−kx-\tfrac1k e^{-kx}−k1​e−kx, que vai a 000).

Teste da comparação

Sejam fff e ggg contínuas em [a,+∞)[a, +\infty)[a,+∞) com

0≤f(x)≤g(x)para todo x≥a 0 \le f(x) \le g(x) \quad\text{para todo } x \ge a 0≤f(x)≤g(x)para todo x≥a

Então:

  • se ∫a+∞g\displaystyle\int_a^{+\infty} g∫a+∞​g converge, então ∫a+∞f\displaystyle\int_a^{+\infty} f∫a+∞​f converge (maior converge, menor converge);
  • se ∫a+∞f\displaystyle\int_a^{+\infty} f∫a+∞​f diverge, então ∫a+∞g\displaystyle\int_a^{+\infty} g∫a+∞​g diverge (menor diverge, maior diverge).

Atenção

As outras duas direções não dão conclusão. Se a maior diverge, a menor pode ir para qualquer lado. Se a menor converge, a maior pode ir para qualquer lado. E a condição 0≤f0 \le f0≤f é obrigatória.

Comportamento no infinito

Para escolher a comparação certa, ajuda saber quem “vence” quando x→∞x \to \inftyx→∞ (por L’Hôpital):

lim⁡x→∞logaritmopoteˆncia de x=0lim⁡x→∞poteˆncia de xexponencial=0 \lim_{x\to\infty}\frac{\text{logaritmo}}{\text{potência de }x} = 0 \qquad\qquad \lim_{x\to\infty}\frac{\text{potência de }x}{\text{exponencial}} = 0 x→∞lim​poteˆncia de xlogaritmo​=0x→∞lim​exponencialpoteˆncia de x​=0

Em ordem de crescimento: logaritmo < potência < exponencial.

Teste da comparação no limite

Sejam fff e ggg contínuas e positivas em [a,+∞)[a, +\infty)[a,+∞). Se

lim⁡x→+∞f(x)g(x)=L,0<L<+∞ \lim_{x\to+\infty}\frac{f(x)}{g(x)} = L, \qquad 0 < L < +\infty x→+∞lim​g(x)f(x)​=L,0<L<+∞

então ∫a+∞f\displaystyle\int_a^{+\infty}f∫a+∞​f e ∫a+∞g\displaystyle\int_a^{+\infty}g∫a+∞​g ambas convergem ou ambas divergem.

Em palavras: se as duas funções “se parecem” no infinito (razão tendendo a um número positivo), elas têm o mesmo destino.

Receita

  1. Olhe o que manda no infinito. Em frações de polinômios, ignore os termos de menor grau: x+1x3+x\dfrac{x+1}{x^3+x}x3+xx+1​ se comporta como xx3=1x2\dfrac{x}{x^3} = \dfrac1{x^2}x3x​=x21​.
  2. Escolha uma função ggg conhecida, quase sempre 1xp\dfrac1{x^p}xp1​ ou e−kxe^{-kx}e−kx.
  3. Escolha o teste:
    • Desigualdade fácil de provar? Comparação direta (precisa de 0≤f≤g0 \le f \le g0≤f≤g).
    • Funções parecidas? Comparação no limite (calcule f/gf/gf/g).
  4. Conclua usando o resultado da ggg.

Exemplos

Exemplo 1. ∫1+∞e−x2 dx\displaystyle\int_1^{+\infty}e^{-x^2}\,dx∫1+∞​e−x2dx

Passo 1. Não há primitiva elementar, então vamos comparar. Passo 2. Para x≥1x \ge 1x≥1 vale x2≥xx^2 \ge xx2≥x (multiplique x≥1x\ge1x≥1 por x>0x>0x>0). Multiplicando por −1-1−1, a desigualdade inverte: −x2≤−x-x^2 \le -x−x2≤−x. Como a exponencial é crescente:

0<e−x2≤e−x 0 < e^{-x^2} \le e^{-x} 0<e−x2≤e−x

Passo 3. ∫1+∞e−x dx=lim⁡b→∞[−e−x]1b=0+e−1=e−1\displaystyle\int_1^{+\infty}e^{-x}\,dx = \lim_{b\to\infty}\big[-e^{-x}\big]_1^b = 0 + e^{-1} = e^{-1}∫1+∞​e−xdx=b→∞lim​[−e−x]1b​=0+e−1=e−1 converge. Pelo teste da comparação (maior converge, menor converge), ∫1+∞e−x2 dx\displaystyle\int_1^{+\infty}e^{-x^2}\,dx∫1+∞​e−x2dx converge.

Exemplo 2. ∫1+∞sen⁡2xx2 dx\displaystyle\int_1^{+\infty}\frac{\operatorname{sen}^2 x}{x^2}\,dx∫1+∞​x2sen2x​dx

Passo 1. Como 0≤sen⁡2x≤10 \le \operatorname{sen}^2 x \le 10≤sen2x≤1, dividindo por x2>0x^2>0x2>0:

0≤sen⁡2xx2≤1x2 0 \le \frac{\operatorname{sen}^2 x}{x^2} \le \frac{1}{x^2} 0≤x2sen2x​≤x21​

Passo 2. ∫1+∞dxx2\displaystyle\int_1^{+\infty}\frac{dx}{x^2}∫1+∞​x2dx​ converge (p=2>1p = 2 > 1p=2>1). Logo a integral converge.

Exemplo 3. ∫1+∞11+x2 dx\displaystyle\int_1^{+\infty}\frac{1}{1+x^2}\,dx∫1+∞​1+x21​dx

Passo 1. Compare com g(x)=1x2g(x) = \dfrac{1}{x^2}g(x)=x21​:

lim⁡x→∞1/(1+x2)1/x2=lim⁡x→∞x21+x2=lim⁡x→∞11x2+1=1 \lim_{x\to\infty}\frac{1/(1+x^2)}{1/x^2} = \lim_{x\to\infty}\frac{x^2}{1+x^2} = \lim_{x\to\infty}\frac{1}{\frac1{x^2}+1} = 1 x→∞lim​1/x21/(1+x2)​=x→∞lim​1+x2x2​=x→∞lim​x21​+11​=1

Passo 2. Como 0<1<∞0 < 1 < \infty0<1<∞ e ∫1∞x−2 dx\int_1^\infty x^{-2}\,dx∫1∞​x−2dx converge, a integral converge.

Exemplo 4. ∫1+∞1−e−xx dx\displaystyle\int_1^{+\infty}\frac{1-e^{-x}}{x}\,dx∫1+∞​x1−e−x​dx

Passo 1. Para xxx grande, e−xe^{-x}e−x é minúsculo, então o numerador tende a 111 e a função se parece com 1x\dfrac1xx1​. Compare com g(x)=1xg(x) = \dfrac1xg(x)=x1​:

lim⁡x→∞(1−e−x)/x1/x=lim⁡x→∞(1−e−x)=1−0=1 \lim_{x\to\infty}\frac{(1-e^{-x})/x}{1/x} = \lim_{x\to\infty}\big(1 - e^{-x}\big) = 1 - 0 = 1 x→∞lim​1/x(1−e−x)/x​=x→∞lim​(1−e−x)=1−0=1

Passo 2. Como ∫1∞dxx\int_1^\infty\frac{dx}{x}∫1∞​xdx​ diverge, a integral dada também diverge.

Extra 1: comparação perto de uma assíntota vertical

Os testes valem também para integrais do Tipo 2 (função que explode em um extremo). Se f,gf,gf,g são contínuas em (a,b](a,b](a,b], com 0≤f≤g0\le f\le g0≤f≤g e a singularidade em aaa:

  • se ∫abg\int_a^b g∫ab​g converge, então ∫abf\int_a^b f∫ab​f converge;
  • se ∫abf\int_a^b f∫ab​f diverge, então ∫abg\int_a^b g∫ab​g diverge.

A “régua” aqui é a integral que você já conhece:

∫01dxxp converge  ⟺  p<1(ao contraˊrio do Tipo 1, onde convergia para p>1) \int_0^1\frac{dx}{x^p}\ \text{converge}\iff p<1\qquad(\text{ao contrário do Tipo 1, onde convergia para } p>1) ∫01​xpdx​ converge⟺p<1(ao contraˊrio do Tipo 1, onde convergia para p>1)

Dica

Memória: perto de 000, x−px^{-p}x−p com ppp pequeno é “fraco” e integra; no infinito, x−px^{-p}x−p precisa de ppp grande. Os dois lados da fronteira p=1p=1p=1 trocam de papel.

Exemplo A. ∫01e−xx dx\displaystyle\int_0^1\frac{e^{-x}}{\sqrt x}\,dx∫01​x​e−x​dx. Em [0,1][0,1][0,1], e−x≤1e^{-x}\le1e−x≤1, logo e−xx≤1x\dfrac{e^{-x}}{\sqrt x}\le\dfrac1{\sqrt x}x​e−x​≤x​1​, e ∫01x−1/2dx\int_0^1x^{-1/2}dx∫01​x−1/2dx converge (p=12<1p=\tfrac12<1p=21​<1). Converge.

Exemplo B. ∫01dxx+x2\displaystyle\int_0^1\frac{dx}{x+x^2}∫01​x+x2dx​. Em (0,1](0,1](0,1], x2≤xx^2\le xx2≤x, então x+x2≤2xx+x^2\le2xx+x2≤2x. Invertendo (tudo positivo), 1x+x2≥12x\dfrac1{x+x^2}\ge\dfrac1{2x}x+x21​≥2x1​, e ∫01dx2x\int_0^1\frac{dx}{2x}∫01​2xdx​ diverge. Diverge.

Exemplo C (limite). ∫01sen⁡xx3/2 dx\displaystyle\int_0^1\frac{\operatorname{sen}x}{x^{3/2}}\,dx∫01​x3/2senx​dx. Comparando com g(x)=x−1/2g(x)=x^{-1/2}g(x)=x−1/2:

lim⁡x→0+sen⁡x/x3/2x−1/2=lim⁡x→0+sen⁡xx3/2⋅x1/2=lim⁡x→0+sen⁡xx=1∈(0,∞) \lim_{x\to0^+}\frac{\operatorname{sen}x/x^{3/2}}{x^{-1/2}}=\lim_{x\to0^+}\frac{\operatorname{sen}x}{x^{3/2}}\cdot x^{1/2}=\lim_{x\to0^+}\frac{\operatorname{sen}x}{x}=1\in(0,\infty) x→0+lim​x−1/2senx/x3/2​=x→0+lim​x3/2senx​⋅x1/2=x→0+lim​xsenx​=1∈(0,∞)

Como ∫01x−1/2dx\int_0^1x^{-1/2}dx∫01​x−1/2dx converge, a nossa também converge.

Extra 2: integrando que troca de sinal (convergência absoluta)

Os testes acima exigem f≥0f\ge0f≥0. Se fff oscila (muda de sinal), use:

Se ∫∣f∣\int\lvert f\rvert∫∣f∣ converge, então ∫f\int f∫f converge.

(A recíproca é falsa.) Procedimento: limite ∣f∣\lvert f\rvert∣f∣ por algo conhecido e use comparação.

Exemplo D. ∫1∞sen⁡xx2 dx\displaystyle\int_1^{\infty}\frac{\operatorname{sen}x}{x^2}\,dx∫1∞​x2senx​dx. Como ∣sen⁡x∣≤1\lvert\operatorname{sen}x\rvert\le1∣senx∣≤1, ∣sen⁡xx2∣≤1x2\left\lvert\dfrac{\operatorname{sen}x}{x^2}\right\rvert\le\dfrac1{x^2}​x2senx​​≤x21​, e ∫1∞x−2dx\int_1^\infty x^{-2}dx∫1∞​x−2dx converge. Logo a integral original converge (absolutamente).

Exercícios propostos

Exercício 1. Estude a convergência de ∫1+∞x+1x3+x dx\displaystyle\int_1^{+\infty}\frac{x+1}{x^3+x}\,dx∫1+∞​x3+xx+1​dx.

Gabarito

Passo 1. Para xxx grande, x+1x3+x\dfrac{x+1}{x^3+x}x3+xx+1​ se parece com xx3=1x2\dfrac{x}{x^3} = \dfrac{1}{x^2}x3x​=x21​. Passo 2. Comparando no limite:

lim⁡x→∞(x+1)/(x3+x)1/x2=lim⁡x→∞x2(x+1)x3+x=lim⁡x→∞x3+x2x3+x=lim⁡x→∞1+1x1+1x2=1 \lim_{x\to\infty}\frac{(x+1)/(x^3+x)}{1/x^2} = \lim_{x\to\infty}\frac{x^2(x+1)}{x^3+x} = \lim_{x\to\infty}\frac{x^3+x^2}{x^3+x} = \lim_{x\to\infty}\frac{1+\frac1x}{1+\frac1{x^2}} = 1 x→∞lim​1/x2(x+1)/(x3+x)​=x→∞lim​x3+xx2(x+1)​=x→∞lim​x3+xx3+x2​=x→∞lim​1+x21​1+x1​​=1

Passo 3. Como ∫1∞x−2 dx\int_1^\infty x^{-2}\,dx∫1∞​x−2dx converge, a integral converge.

Exercício 2. Estude a convergência de ∫1+∞dxx+1\displaystyle\int_1^{+\infty}\frac{dx}{\sqrt x + 1}∫1+∞​x​+1dx​.

Gabarito

Passo 1. Para xxx grande, se parece com 1x\dfrac{1}{\sqrt x}x​1​ (p=12p = \tfrac12p=21​). Passo 2. No limite:

lim⁡x→∞1/(x+1)1/x=lim⁡x→∞xx+1=lim⁡x→∞11+1x=1 \lim_{x\to\infty}\frac{1/(\sqrt x+1)}{1/\sqrt x} = \lim_{x\to\infty}\frac{\sqrt x}{\sqrt x+1} = \lim_{x\to\infty}\frac{1}{1+\frac{1}{\sqrt x}} = 1 x→∞lim​1/x​1/(x​+1)​=x→∞lim​x​+1x​​=x→∞lim​1+x​1​1​=1

Passo 3. Como ∫1∞x−1/2 dx\int_1^\infty x^{-1/2}\,dx∫1∞​x−1/2dx diverge, a integral diverge.

Exercício 3. Estude a convergência de ∫1+∞cos⁡2xx2+1 dx\displaystyle\int_1^{+\infty}\frac{\cos^2 x}{x^2+1}\,dx∫1+∞​x2+1cos2x​dx.

Gabarito

Passo 1. Como 0≤cos⁡2x≤10 \le \cos^2 x \le 10≤cos2x≤1 e x2+1>x2x^2 + 1 > x^2x2+1>x2 (logo 1x2+1<1x2\frac{1}{x^2+1}<\frac1{x^2}x2+11​<x21​):

0≤cos⁡2xx2+1≤1x2+1≤1x2 0 \le \frac{\cos^2 x}{x^2+1} \le \frac{1}{x^2+1} \le \frac{1}{x^2} 0≤x2+1cos2x​≤x2+11​≤x21​

Passo 2. e ∫1∞x−2 dx\int_1^\infty x^{-2}\,dx∫1∞​x−2dx converge. Logo a integral converge (comparação direta).

Exercício 4. Estude a convergência de ∫e+∞ln⁡xx dx\displaystyle\int_e^{+\infty}\frac{\ln x}{x}\,dx∫e+∞​xlnx​dx.

Gabarito

Passo 1. Para x≥ex \ge ex≥e, ln⁡x≥ln⁡e=1\ln x \ge \ln e = 1lnx≥lne=1, então

ln⁡xx≥1x≥0 \frac{\ln x}{x} \ge \frac1x \ge 0 xlnx​≥x1​≥0

Passo 2. e ∫e∞dxx\int_e^\infty\frac{dx}{x}∫e∞​xdx​ diverge. Pela comparação (menor diverge, maior diverge), a integral diverge.

Exercício extra 1. Estude ∫01dxx+x3\displaystyle\int_0^1\frac{dx}{\sqrt{x+x^3}}∫01​x+x3​dx​.

Passo 1. Como x+x3≥xx+x^3\ge xx+x3≥x, x+x3≥x\sqrt{x+x^3}\ge\sqrt xx+x3​≥x​, e invertendo, 1x+x3≤1x\dfrac1{\sqrt{x+x^3}}\le\dfrac1{\sqrt x}x+x3​1​≤x​1​. Passo 2. ∫01x−1/2dx\int_0^1x^{-1/2}dx∫01​x−1/2dx converge. Converge.
