1. Por que inventar uma linguagem?

Uma piada clássica:

Um homem vai ao mercado. A esposa pede: “Traga um litro de leite e, se tiver ovos, compre uma dúzia.” Ele volta com treze litros de leite. “Por quê?” — “Porque tinha ovos.”

O português é ambíguo: “se tiver ovos, compre uma dúzia” pode ser “uma dúzia de ovos” ou “uma dúzia de litros de leite”. Em lógica (e em programação!) ambiguidade é inaceitável.

A lógica proposicional é uma linguagem sem ambiguidade: cada fórmula tem uma única leitura.

Além disso, ela é simbólica: o que importa é a forma, não o assunto. Veja:

Argumento AArgumento B
Se chover hoje, haverá enchente.Se você vier, não preciso ir.
Choveu hoje.Você vem.
Então houve enchente.Então não preciso ir.

Assuntos diferentes, mesma forma: se ppp então qqq; ppp; logo qqq. Trocando frases por letras, enxergamos o esqueleto do raciocínio.

2. O alfabeto

A linguagem tem três tipos de peças:

(a) Letras proposicionais (átomos)

Cada letra representa uma proposição simples, que não pode ser quebrada em pedaços menores com “e”, “ou”, “se”, “não”.

  • ppp: “Choveu em Campina Grande hoje.”
  • qqq: “Cachorros latem.”
  • rrr: “Wilson é um aluno aplicado.”

Dica

Como saber se é átomo? Tente quebrar com um conectivo. “Choveu e fez frio” quebra em dois átomos (“choveu”, “fez frio”). “Choveu” não quebra. Átomos também são chamados de fórmulas atômicas.

(b) Conectivos

São as “cola” que juntam átomos:

NomeSímboloLê-seIdeia em uma frase
Negação¬p\neg p¬p“não ppp”, “é falso que ppp”inverte
Conjunçãop∧qp\land qp∧q“ppp e qqq”os dois
Disjunçãop∨qp\lor qp∨q“ppp ou qqq”pelo menos um
Implicaçãop→qp\to qp→q“se ppp, então qqq”promessa
Bicondicionalp↔qp\leftrightarrow qp↔q“ppp se, e somente se, qqq”andam juntos

Conectivos estendidos (atalhos úteis):

NomeSímboloSignifica
Ou exclusivo (XOR)p⊕qp\oplus qp⊕qppp ou qqq, mas não ambos
NANDp↑qp\uparrow qp↑q“não ambos”: ¬(p∧q)\neg(p\land q)¬(p∧q)
NORp↓qp\downarrow qp↓q“nem um nem outro”: ¬(p∨q)\neg(p\lor q)¬(p∨q)

(c) Parênteses

Servem para tirar a ambiguidade. É a versão lógica de “(leite + ovos) × dúzia” versus “leite + (ovos × dúzia)”.

3. Fórmulas bem formadas

Nem toda sequência de símbolos é uma fórmula. As regras de construção são:

  1. Toda letra proposicional é uma fórmula.
  2. Se AAA é fórmula, então ¬A\neg A¬A também é.
  3. Se AAA e BBB são fórmulas, então (A∧B)(A\land B)(A∧B), (A∨B)(A\lor B)(A∨B), (A→B)(A\to B)(A→B) e (A↔B)(A\leftrightarrow B)(A↔B) também são.
  4. Nada mais é fórmula.

Pense em montar LEGO: só vale encaixe permitido.

Exemplo. Quais são bem formadas?

  1. ((P∨Q)→R)((P\lor Q)\to R)((P∨Q)→R) Sim.
  2. (P→↔(RS→))(P\to\leftrightarrow(RS\to))(P→↔(RS→)) Não. Dois conectivos seguidos, “RS” sem conectivo, e uma seta sem o lado direito.
  3. (((P∨R)→T)↔(Q∧S))(((P\lor R)\to T)\leftrightarrow(Q\land S))(((P∨R)→T)↔(Q∧S)) Sim.
  4. (¬P→(Q∧(R↔S)))(¬P→(Q∧(R↔S)))(\neg P\to(Q\land(R\leftrightarrow S)))(\neg P\to(Q\land(R\leftrightarrow S)))(¬P→(Q∧(R↔S)))(¬P→(Q∧(R↔S))) Não. São duas fórmulas coladas, sem conectivo entre elas.

4. Reduzindo parênteses: precedência

Escrever todos os parênteses vira um pesadelo:

(((P∨R)→T)↔(Q∧S)) (((P\lor R)\to T)\leftrightarrow(Q\land S)) (((P∨R)→T)↔(Q∧S))

Por isso há uma ordem de prioridade, igual a ×\times× antes de +++ na matemática:

PrioridadeConectivos
1 (mais forte)¬\neg¬
2∧\land∧, ↑\uparrow↑
3∨\lor∨, ↓\downarrow↓
4→\to→
5 (mais fraco)↔\leftrightarrow↔, ⊕\oplus⊕

Quem tem prioridade maior “agarra” primeiro os vizinhos:

  • p∨q∧rp\lor q\land rp∨q∧r significa p∨(q∧r)p\lor(q\land r)p∨(q∧r), e não (p∨q)∧r(p\lor q)\land r(p∨q)∧r.
  • p→q↔¬q→¬pp\to q\leftrightarrow\neg q\to\neg pp→q↔¬q→¬p significa (p→q)↔((¬q)→(¬p))(p\to q)\leftrightarrow((\neg q)\to(\neg p))(p→q)↔((¬q)→(¬p)).

Associatividade. ∧\land∧ e ∨\lor∨ podem ser agrupados de qualquer jeito: p∨q∨rp\lor q\lor rp∨q∨r é seguro. Já a implicação associa à direita: p→q→rp\to q\to rp→q→r significa p→(q→r)p\to(q\to r)p→(q→r).

Atenção

Na dúvida, use parênteses! Precedência é para economizar tinta, não para deixar a fórmula enigmática. E nunca escreva p→q→rp\to q\to rp→q→r achando que é (p→q)→r(p\to q)\to r(p→q)→r: são coisas diferentes.

5. Ponte com a programação

Os conectivos são os operadores booleanos que você já usa:

LógicaCódigo
¬p\neg p¬p!p
p∧qp\land qp∧qp && q
p∨qp\lor qp∨qp || q
p⊕qp\oplus qp⊕qp != q (para booleanos)

Exemplo. Traduza if ((x > 0) || (x <= 0 && y > 100)).

  • ppp: “x>0x>0x>0” e qqq: “y>100y>100y>100”. Note que “x≤0x\le0x≤0” é exatamente ¬p\neg p¬p.
  • Fórmula: p∨(¬p∧q)p\lor(\neg p\land q)p∨(¬p∧q).

Curiosidade: essa condição pode ser simplificada para p∨qp\lor qp∨q, isto é, if (x > 0 || y > 100). (Veja por quê na página de Tabela-verdade.) Lógica serve para deixar código mais limpo.

Resumo

  • Lógica proposicional é uma linguagem sem ambiguidade e simbólica.
  • Peças: letras (átomos), conectivos (¬,∧,∨,→,↔\neg,\land,\lor,\to,\leftrightarrow¬,∧,∨,→,↔) e parênteses.
  • Precedência: ¬\neg¬ > ∧\land∧ > ∨\lor∨ > →\to→ > ↔\leftrightarrow↔. Na dúvida, parênteses.

Exercícios

Exercício 1. (P∧→Q)(P\land\to Q)(P∧→Q) é fórmula bem formada?

A expressão (P∧→Q)(P\land\to Q)(P∧→Q) é uma fórmula bem formada?

Não: falta uma fórmula antes da seta (dois conectivos seguidos, ∧→\land\to∧→).

Exercício 2. Coloque os parênteses completos em p∧q→r∨sp\land q\to r\lor sp∧q→r∨s.

Com todos os parênteses, p∧q→r∨sp\land q\to r\lor sp∧q→r∨s fica:

∧\land∧ e ∨\lor∨ agarram primeiro; o →\to→ fica por último e liga os dois blocos.

Exercício 3. Coloque os parênteses completos em ¬p∨q→r\neg p\lor q\to r¬p∨q→r.

Com todos os parênteses, ¬p∨q→r\neg p\lor q\to r¬p∨q→r fica:

O ¬\neg¬ só atinge o ppp; depois vem o ∨\lor∨; e o →\to→ fica por último.

Exercício 4. Traduza if (a > 0 && !(b > 0)).

Gabarito

ppp: “a>0a>0a>0”, qqq: “b>0b>0b>0”. Fórmula: p∧¬qp\land\neg qp∧¬q.
