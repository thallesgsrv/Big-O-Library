Sobre

Até aqui, para saber se uma fórmula é válida, olhamos mundos possíveis (linhas da tabela, ramos do tableaux). O método axiomático faz diferente: escolhemos algumas fórmulas “de confiança” (os axiomas), algumas regras de transformação, e provamos novas fórmulas só encadeando essas regras, sem nunca mencionar V ou F.

É o jeito mais antigo e mais enxuto de fazer lógica formal: poucos ingredientes, mas provas longas.

Ao final você deve conseguir:

  • explicar o que é um sistema dedutivo e o que significam solidez, completude e decidibilidade;
  • reconhecer instâncias de um axioma (esquema);
  • aplicar Modus Ponens;
  • ler e montar uma prova axiomática, com ou sem premissas;
  • reescrever ∧,∨,↔\land,\lor,\leftrightarrow∧,∨,↔ usando só →\to→ e ¬\neg¬.

1. Sistemas dedutivos

Um sistema dedutivo é uma “máquina de provar” com três partes:

  1. Símbolos e regras de formação: quais fórmulas existem (Linguagem).
  2. Axiomas: fórmulas aceitas sem prova (nem todo sistema tem; veremos a dedução natural, que não tem).
  3. Regras de inferência: como produzir fórmulas novas a partir de outras.

Uma prova formal é uma lista numerada: cada linha é uma fórmula com uma justificativa (axioma, premissa ou regra aplicada a linhas anteriores). A última linha é a conclusão.

1. (fórmula)   justificativa
2. (fórmula)   justificativa
...
n. conclusão

Escrevemos Γ⊢ψ\Gamma\vdash\psiΓ⊢ψ (“de Γ\GammaΓ se deriva ψ\psiψ”) quando existe uma prova assim, e ⊢ψ\vdash\psi⊢ψ quando não precisamos de premissas (ψ\psiψ é um teorema).

O que esperamos de um bom sistema

PropriedadeEm palavrasEm símbolos
Solidez (soundness)O que o sistema prova é de fato válido. Não prova mentira.Γ⊢ψ ⇒ Γ⊨ψ\Gamma\vdash\psi\ \Rightarrow\ \Gamma\models\psiΓ⊢ψ ⇒ Γ⊨ψ
CompletudeTudo que é válido o sistema consegue provar. Não deixa verdade de fora.Γ⊨ψ ⇒ Γ⊢ψ\Gamma\models\psi\ \Rightarrow\ \Gamma\vdash\psiΓ⊨ψ ⇒ Γ⊢ψ
DecidibilidadeExiste um algoritmo que, em passos finitos, diz se uma fórmula é tautologia (ou se um argumento é válido).

Para a lógica proposicional, os sistemas deste estágio são sólidos e completos: ⊢\vdash⊢ e ⊨\models⊨ dizem exatamente a mesma coisa, só por caminhos diferentes. E a lógica proposicional é decidível (a tabela-verdade é o algoritmo).

Nota

Cuidado com a palavra “sólido/correto”. Na página de conceitos, “argumento correto” significa válido e com premissas realmente verdadeiras. Aqui, “solidez” é uma propriedade do sistema de prova. São usos diferentes da mesma palavra.

2. Axiomas e regras de inferência

Axioma = esquema de fórmula

Um axioma é uma fórmula que já sabemos ser válida no sistema. Na prática, é um molde com letras gregas (α,β,γ\alpha,\beta,\gammaα,β,γ) que podem ser trocadas por qualquer fórmula.

α→(β→α) \alpha\to(\beta\to\alpha) α→(β→α)

Trocando α=¬p\alpha=\neg pα=¬p e β=q\beta=qβ=q, obtemos a instância:

¬p→(q→¬p) \neg p\to(q\to\neg p) ¬p→(q→¬p)

Importante

A troca é uniforme: o mesmo α\alphaα vira a mesma fórmula em todos os lugares onde aparece. Em α→(β→α)\alpha\to(\beta\to\alpha)α→(β→α), os dois α\alphaα precisam virar a mesma coisa. Já α\alphaα e β\betaβ podem virar fórmulas iguais ou diferentes.

Regra de inferência = transformação sintática segura

É uma regra que olha só para a forma das fórmulas. O exemplo clássico é o Modus Ponens (MP):

αα→ββ MP \frac{\alpha\qquad\alpha\to\beta}{\beta}\ \text{MP} βαα→β​ MP

Se já temos α\alphaα e também α→β\alpha\to\betaα→β, podemos escrever β\betaβ. É o mesmo →e\to e→e que você vai ver na dedução natural.

3. Um sistema de exemplo: Hilbert com →\to→ e ¬\neg¬

Chamemos este sistema de ZZZ. Ele só tem implicação e negação como conectivos primitivos.

Axiomas

ItemEsquema
(A1)α→(β→α)\alpha\to(\beta\to\alpha)α→(β→α)
(A2)(α→(β→γ))→((α→β)→(α→γ))(\alpha\to(\beta\to\gamma))\to((\alpha\to\beta)\to(\alpha\to\gamma))(α→(β→γ))→((α→β)→(α→γ))
(A3)(¬β→¬α)→((¬β→α)→β)(\neg\beta\to\neg\alpha)\to((\neg\beta\to\alpha)\to\beta)(¬β→¬α)→((¬β→α)→β)

Regra

(R1) MPde α\alphaα e α→β\alpha\to\betaα→β, conclui β\betaβ

Só isso. Três esquemas de axioma e uma regra são suficientes para provar toda tautologia que use →\to→ e ¬\neg¬.

Estrutura de uma prova axiomática

Cada linha da prova é uma destas três coisas:

  1. uma instância de axioma (anotando qual e quais trocas foram feitas);
  2. uma premissa (quando Γ≠∅\Gamma\neq\varnothingΓ=∅);
  3. o resultado de MP aplicado a duas linhas anteriores (anotando quais).

A última linha é a fórmula provada.

4. Exemplo: provar A→AA\to AA→A

Parece óbvio (se AAA então AAA), mas no sistema ZZZ nada é de graça: precisamos construir.

⊢ZA→A \vdash_Z A\to A ⊢Z​A→A
PassoFórmulaJustificativa
1A→((A→A)→A)A\to((A\to A)\to A)A→((A→A)→A)A1 com α=A\alpha=Aα=A, β=(A→A)\beta=(A\to A)β=(A→A)
2(A→((A→A)→A))→((A→(A→A))→(A→A))(A\to((A\to A)\to A))\to((A\to(A\to A))\to(A\to A))(A→((A→A)→A))→((A→(A→A))→(A→A))A2 com α=A\alpha=Aα=A, β=(A→A)\beta=(A\to A)β=(A→A), γ=A\gamma=Aγ=A
3(A→(A→A))→(A→A)(A\to(A\to A))\to(A\to A)(A→(A→A))→(A→A)MP 1, 2

O subscrito em ⊢Z\vdash_Z⊢Z​ indica qual sistema foi usado.

Dica

Como ler o passo 3: a linha 2 tem a forma X→YX\to YX→Y, onde XXX é exatamente a linha 1. Então MP entrega YYY. Em toda aplicação de MP, localize primeiro a linha que é “α\alphaα” e a que é “α→β\alpha\to\betaα→β”.

Como enxergar a ideia: a prova de A→AA\to AA→A usa A1 duas vezes (com trocas diferentes) e A2 uma vez. É o padrão de “truque” que aparece em quase toda prova axiomática: uma instância de A2 cuja metade é fornecida por A1.

5. Provas com premissas

Quando o argumento tem premissas, elas entram como linhas justificadas por “premissa” (ou “P”). Exemplo: o silogismo hipotético.

P→Q, Q→R ⊢ P→R P\to Q,\ Q\to R\ \vdash\ P\to R P→Q, Q→R ⊢ P→R
PassoFórmulaJustificativa
1P→QP\to QP→Qpremissa
2Q→RQ\to RQ→Rpremissa
3(Q→R)→(P→(Q→R))(Q\to R)\to(P\to(Q\to R))(Q→R)→(P→(Q→R))A1 com α=(Q→R)\alpha=(Q\to R)α=(Q→R), β=P\beta=Pβ=P
4P→(Q→R)P\to(Q\to R)P→(Q→R)MP 2, 3
5(P→(Q→R))→((P→Q)→(P→R))(P\to(Q\to R))\to((P\to Q)\to(P\to R))(P→(Q→R))→((P→Q)→(P→R))A2 com α=P\alpha=Pα=P, β=Q\beta=Qβ=Q, γ=R\gamma=Rγ=R
6(P→Q)→(P→R)(P\to Q)\to(P\to R)(P→Q)→(P→R)MP 4, 5
7P→RP\to RP→RMP 1, 6

Repare no padrão: o passo 3 usa A1 para “carregar” a premissa Q→RQ\to RQ→R para dentro de um P→P\toP→, e o passo 5 usa A2 para “distribuir” o PPP. Depois é só MP.

6. E os outros conectivos?

O sistema ZZZ só conhece →\to→ e ¬\neg¬. Os demais são abreviações (definições):

AbreviaçãoDefinição em →,¬\to,\neg→,¬
α∧β\alpha\land\betaα∧β¬(α→¬β)\neg(\alpha\to\neg\beta)¬(α→¬β)
α∨β\alpha\lor\betaα∨β¬α→β\neg\alpha\to\beta¬α→β
α↔β\alpha\leftrightarrow\betaα↔β¬((α→β)→¬(β→α))\neg\big((\alpha\to\beta)\to\neg(\beta\to\alpha)\big)¬((α→β)→¬(β→α))

Atenção

Cuidado com a conjunção. É ¬(α→¬β)\neg(\alpha\to\neg\beta)¬(α→¬β), com o ¬\neg¬ dentro do segundo argumento. A fórmula ¬(α→β)\neg(\alpha\to\beta)¬(α→β) não é α∧β\alpha\land\betaα∧β: ela diz “α\alphaα e não β\betaβ” (promessa quebrada, lembra do tableaux?). Teste com a tabela: ¬(α→¬β)\neg(\alpha\to\neg\beta)¬(α→¬β) só é V quando α=β=V\alpha=\beta=Vα=β=V.

Exemplo útil: o terceiro excluído. Pela definição de ∨\lor∨:

p∨¬p ≡ ¬p→¬p p\lor\neg p\ \equiv\ \neg p\to\neg p p∨¬p ≡ ¬p→¬p

Logo provar ⊢p∨¬p\vdash p\lor\neg p⊢p∨¬p é provar ⊢¬p→¬p\vdash\neg p\to\neg p⊢¬p→¬p, que é a prova da seção 4 com A:=¬pA:=\neg pA:=¬p em todas as linhas.

7. Axiomático na prática

ItemVantagemDesvantagem
HilbertPoucas regras (só MP), ótimo para estudar o sistema (provar solidez e completude).Provas longas e pouco intuitivas, mesmo para fatos simples.

Por isso, para fazer provas, usamos a dedução natural, que imita o raciocínio do dia a dia.

Dica

Atalho (Teorema da Dedução). Em sistemas como ZZZ vale: Γ,α⊢β\Gamma,\alpha\vdash\betaΓ,α⊢β se, e somente se, Γ⊢α→β\Gamma\vdash\alpha\to\betaΓ⊢α→β. É a versão axiomática da ideia de “supor α\alphaα e chegar em β\betaβ”, e é o que torna as provas com premissas muito mais curtas. A dedução natural embute esse atalho na regra →i\to i→i.

Erros comuns

  • Troca não uniforme. Instanciar α→(β→α)\alpha\to(\beta\to\alpha)α→(β→α) como p→(q→r)p\to(q\to r)p→(q→r) é errado: os dois α\alphaα precisam ser a mesma fórmula.
  • MP “ao contrário”. De β\betaβ e α→β\alpha\to\betaα→β não se conclui α\alphaα (isso é a falácia da afirmação do consequente).
  • Esquecer de anotar a troca. Sem dizer quanto valem α,β,γ\alpha,\beta,\gammaα,β,γ fica difícil de conferir; é a primeira coisa que o corretor procura.
  • Usar MP com fórmulas que “quase” casam. O antecedente de uma linha precisa ser idêntico, símbolo por símbolo, à outra linha.
  • Confundir ⊢\vdash⊢ com ⊨\models⊨. ⊢\vdash⊢ é “tem prova”, ⊨\models⊨ é “é consequência semântica”. Pela solidez e completude dão no mesmo, mas não são a mesma definição.

Resumo

  • Sistema dedutivo = linguagem + (axiomas) + regras de inferência. Prova = lista de fórmulas, cada uma justificada.
  • Solidez: ⊢⇒⊨\vdash\Rightarrow\models⊢⇒⊨. Completude: ⊨⇒⊢\models\Rightarrow\vdash⊨⇒⊢. A lógica proposicional é decidível.
  • Axioma é um esquema; vale qualquer troca uniforme de α,β,γ\alpha,\beta,\gammaα,β,γ por fórmulas.
  • MP: de α\alphaα e α→β\alpha\to\betaα→β, conclui β\betaβ.
  • Sistema ZZZ: A1, A2, A3 e MP. ∧,∨,↔\land,\lor,\leftrightarrow∧,∨,↔ são abreviações em →,¬\to,\neg→,¬.

Exercícios

Qual destas fórmulas é uma instância do axioma A1, α→(β→α)\alpha\to(\beta\to\alpha)α→(β→α)?

Em A1, o consequente interno repete o antecedente externo. Em p→(q→p)p\to(q\to p)p→(q→p): α=p\alpha=pα=p, β=q\beta=qβ=q. Em p→(q→q)p\to(q\to q)p→(q→q) o final seria ppp, não qqq. Em (p→q)→(p→(q→p))(p\to q)\to(p\to(q\to p))(p→q)→(p→(q→p)) teríamos α=p→q\alpha=p\to qα=p→q, e o final deveria ser p→qp\to qp→q, não q→pq\to pq→p. A última repete ¬q\neg q¬q onde deveria repetir ¬p\neg p¬p.

Exercício 1. Mostre que ((p→q)→((q→r)→(p→q)))((p\to q)\to((q\to r)\to(p\to q)))((p→q)→((q→r)→(p→q))) é instância de um axioma e diga quais são as trocas.

Gabarito

É A1, α→(β→α)\alpha\to(\beta\to\alpha)α→(β→α), com α=(p→q)\alpha=(p\to q)α=(p→q) e β=(q→r)\beta=(q\to r)β=(q→r).

Exercício 2. Escreva p∧(q∨r)p\land(q\lor r)p∧(q∨r) usando só →\to→ e ¬\neg¬.

Gabarito

q∨r=¬q→rq\lor r=\neg q\to rq∨r=¬q→r. Então p∧(q∨r)=¬(p→¬(¬q→r))p\land(q\lor r)=\neg\big(p\to\neg(\neg q\to r)\big)p∧(q∨r)=¬(p→¬(¬q→r)).

Gabarito

É a prova da seção 4 trocando AAA por ¬p\neg p¬p em todas as linhas (cinco passos: A1, A2, MP, A1, MP). Como p∨¬pp\lor\neg pp∨¬p é abreviação de ¬p→¬p\neg p\to\neg p¬p→¬p, isso prova o terceiro excluído no sistema ZZZ.

Um sistema dedutivo é sólido quando…

Solidez é Γ⊢ψ⇒Γ⊨ψ\Gamma\vdash\psi\Rightarrow\Gamma\models\psiΓ⊢ψ⇒Γ⊨ψ. A segunda alternativa descreve a completude; a terceira, a decidibilidade; a quarta confunde com “argumento correto”, que é outro conceito.
